## 量纲与物理通路铁律（最易复发）

- 递推与 loss **必须同一变换**（log1p 域）：`L=log1p(a)`→`m=mean_N(L)`→`m_new=m+γ_lvl(μ−m)`→`a_new=expm1(L_new.clamp(0,6))`。改 loss 变换须同步改 block.py + `a_mu` 初值 + μ 的 lr 倍率
- **Jensen 陷阱**：诊断谱包络用 `mean_N(log)` 不是 `log(mean_N(a))`（corr 0.9953 vs 0.8674）
- **漂移场是唯一把 target 送进相位演化的通路**（正磁场不带 target 信息，缺一就死），须在**相位空间**定义
- **ω 必须确定性**（重采样 = 换动力系统）；振幅演化必须 **log 域乘性** `a·exp(clamp(x,−6,3))`
- 相位 loss 按 `a_tar²` 功率加权；**OU 平衡点必须 per-channel**（每通道振幅均值跨 727 倍）

## 编解码口径

- **真实网格 = 5×25 = 125**。通道 c ↔ (h=c//25, **w=c%25**)，**分频段按 w 切**（均分会混淆 DC 与高频）。c=0/25/50 是 w=0 列，承载 97.2% 能量
- **★★ 颜色的唯一载体是 w=16（2026-10-24 实测确认，最重要）**：`s_dim = 4×4×3 = 48`，颜色通道 ch 是这 48 维的**最后一位**，周期=3 → 沿 48 维 rfft 后色差落在 **w = 48/3 = 16**。实验铁证（去掉/只留 w=16 后重建）：
  | 素材 | 完整 sat | 去掉 w=16 | 只留 w=16(+DC) |
  |---|---|---|---|
  | 8-ball | 6.36 | **0.51**（色没了） | **6.85**（色完整） |
  | 前辈前辈 | 9.87 | **2.85** | **9.79**（色完整） |
  → **颜色 = 通道 c ∈ {16,41,66,91,116}（即 c%25==16 的 5 个时间频段）**，其余 120 个通道对颜色几乎无贡献。**要治颜色，必须直接约束这 5 个通道的 amp/phase，在空间域算 sat 是舍近求远**
- **颜色丢失的确切病灶（2026-10-24 频域实测）**：color4 生成场在 **w=16 只有 target 的 12~17%**（8-ball 0.103 vs 0.616；前辈前辈 0.139 vs 1.140），而 **w=0（亮度）是 target 的 1.35~1.43 倍（过亮）**，w=12/15/17/20 反而 13~17 倍（是噪声不是色）。即"低频过学、颜色频点欠学"
- `load_gif_frames` 必须**逐帧 seek 后再 convert("RGB")**（否则压成单帧）；encode `NORM=10.0`，评估双侧同口径
- **★ d_model 非对称硬截断是 LED 网格感真凶**。旧结论「d_model 不是瓶颈」**已作废**——全保留 125 系数实测 PSNR 147.20 dB、网格比=素材原值 → **FFT 往返零噪声，网格感 100% 来自截断**
- 窗函数必须在 (h=0,w=0) 处=1.0（Hann 会压掉 79.7% 能量的直流）

## 度量陷阱（平均值骗人）

- log 域振幅比/wcos/能量占比**全是平均值度量**，对比度损失恰在其中抵消。**必须同时报空间域指标**（对比度 std、p1–p99、Sobel）
- **log1p 关不住尖峰**（a=148 时梯度仅线性域 0.67%）→ 修法 = 逐通道**能量比 log 差**
- **消融铁律**：频段能量失真与 PSNR 退化是**两个独立问题**，必须分开治
- **全局对比度 loss 会牺牲低对比度帧** → 必须逐帧 + 判据相对 target
- **均值约束降噪 = 压平轮廓（"模糊"）** → 用分位数约束（高端 q99 用 relu 单侧保护）
- 降噪/锐度验收**以原始素材为及格线**，不能拿 v2500 当基准

## 已知死穴

1. d_model 非对称硬截断 → 网格感
2. 条件相位预测方向偏 1.35 rad + 漂移场净力被多尺度平均稀释
3. loss_sep 符号写反（应 `clamp(min=0)`）→ 模型狂刷负奖励
4. **口径隔离**：训练 patch 频域 ≠ 图像全局频域，守卫在"自欺域"里工作，slack 须按图像空间后果标定
5. 时间频率 h 维度零监督
6. 物理核递推 + a0 初始化 + loss 口径 + 条件通路是**咬合整体**，禁止只换一环
7. **★ `COND_INIT_PC` 无默认 = 静默白跑**：v4200 漏设该变量会退化成旧 Modulator（10.27M vs 23.04M），`RESUME` 再把 `cond_init.*` 当 shape 不匹配跳过 → 条件通路随机初始化。已给 `train_guided.py` 补默认值，并加「跳过关键条件层就中止」保护
8. **★ 颜色 loss 权重过高会牺牲视频再生分支（第三十八死穴）**：COLOR_W=2.0 让纯生成 sat 达标（≈素材）但视频再生被压垮（sat 2.1、洗白偏亮）、旁路差距从 +0.15 dB 退回 −0.81 dB。**W=1.0 是分支均衡点**。调 COLOR_W 必须同时看纯生成 sat 与视频再生 sat，只看前者会误判成功

- 推进重点：三路向量（文本/图片/视频）→ 生成 → 解决泛化

**因此技术评估口径改为「能力三级判据」，不再用 PSNR/质量绝对值否定**：

| 级别 | 判据 | 当前状态 |
|---|---|---|
| **L1 形式通路** | 三路条件向量都能驱动生成、不出错 | ✅ **已达成** |
| **L2 条件敏感** | 不同向量 → 显著不同的输出（sat 极差 >10；或相对判据正确率 >80%） | ❌ **未达成**（sat 极差 3.96；相对判据 50%，随机） |
| **L3 语义对应** | 生成内容与目标素材语义/结构对应 | ❌ 未达成 |

★ **关键概念区分（必须反复讲清）：「条件通路打通」≠「生成能力成立」**。
只要不同向量输出近似同一张图，"基于向量生成"这个能力就不成立，
评审一问「换段文本结果会变吗」就穿。所以 L2 是当前唯一该攻的判据。
★ 网格噪声属于 L3 之后的问题，**确实可以后置**，不影响 L1/L2 判定。
