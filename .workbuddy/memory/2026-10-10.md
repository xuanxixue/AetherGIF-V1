# 2026-10-10 工作日志

## 振幅"糊"死穴的根治（第九、十死穴）

用户反馈 2500 步结果"85% 但有噪声、还是糊"，本轮定位并修复了谱形状不收敛的根因。

### 诊断（diag_amp.py 层级归因，2500 步 checkpoint）
- 终态层级高出 target 1.87×（OU 锚 μ 合计 −1.482、FFN 残差 r̄ 合计 −0.899）
- a_mu span 只学到 0.06~0.11（target 对数谱 span 6.589），谱形状（即"细节/纹理"）根本没学
- 根因 = 单 γ 的 OU 把"层级收敛"和"形状衰减"绑死：γ=0.3 时形状被压到 1.4%，γ 自学到 0.04 时初值层级残留 61% 洗不掉；FFN 残差 r̄ 与 μ 都能改层级（1 步路径），梯度抄近路走 r̄，μ 被架空

### 修复（方案 F，三处）
1. `src/physics/block.py`：γ 拆 `a_gamma_lvl=0.5`（层级，冻结）+ `a_gamma_shape=0.1`（形状，冻结）；res 逐通道零均值（只含形状）；层级/形状正交递推 `m_new=m+γ_lvl(μ−m)`、`δ_new=(1−γ_shape)δ+res`
2. μ 在 block 间共享（第十死穴）：11 块各一个 μ 时梯度指数衰减，共享后单参数直通路径
3. loss 改 log 域相对误差（前提是正交分离消除了"低频饱和→高频补偿"串扰）+ 分组 lr（a_mu ×100）

### 结果（150 步验证）
- profile_cos 0.186→0.972，谱跨 1x→98x（target 727x），ratio_logstd 1.156→0.298
- 频段比 2.0/2.1/2.1/2.2（均匀，无高频过冲）
- frame-diff 从 10.26 降到 2.71（低于 target 5.56）即噪声已解决；谱展开期短暂反弹到 8.51
- PSNR 14.52→15.64（还在上升）

### 纪律
- 用户明确拒绝"注入数据先验"（set_amp_prior 用 target 谱初始化 μ）= 偷懒不允许，已删除。正确解法是分组学习率让 μ 自己跨 6.6 个 log 单位

## 深夜续：方案 F 1000 步 + 方案 G + 评估口径修正（第十一死穴）

### 方案 F 1000 步结果
- profile_cos 0.994、谱跨 638x（target 727x）——谱形状接近完美
- 但频段比 1.4 整体偏高、frame-diff 反升到 11.21（μ lr×100 震荡：谱跨 522↔909 跳）

### AMP_P 权重的方向效应（算出 log 域加权是多余的）
- p=0.5 → 频段比 1.4 偏高；p=0.25 → 0.6 偏低。根因：log 域已是"倍数"度量，再叠幅度权重等于重新按幅度给 DC 加权（p=0.5 时 DC 权重是高频 5.8 倍），μ 稳态被大通道主导。p 小只是把同一偏置摊平、收敛更慢。

### 方案 G（当前最优）：log 域无权重 + 软截断
- `la=log(a.clamp(0.01))`、`lt=log(a_tar.clamp(0.01))`、`loss_amp=(la-lt)².mean()`，不加任何幅度权重
- <0.01 近零系数（69.4%，功率≈0）误差自动归零不污染；≥0.01 有效系数 log 域平等回归
- μ lr×80，1000 步：profile_cos 0.975、谱跨 822x（target 727x，最接近）、frame-diff **5.91（target 5.56，历史最佳，噪声达标）**、a_out 0.224

### 【第十一死穴：评估口径污染 PSNR】
- 之前所有方案的 PSNR 都在 normalize=False（固定 clamp）下测。诊断（diag_scale.py 振幅缩放扫描）证明：
  - normalize=True（min-max）：PSNR 对振幅缩放**完全不敏感**（scale 0.5~2.0 全是 21.43 dB）→ 这才是真实重建质量
  - normalize=False（固定 clamp）：PSNR 对振幅标度敏感（峰值 scale=0.70，19.25 dB），模型振幅偏小 30% 会让 pix_mean 只有 78（target 95.3）、图像偏暗，PSNR 被亮度偏移拖垮 2~4 dB
- **方案 G 真实重建质量 = 21.43 dB**（不是 clamp 口径的 17.71）；方案 D/F 的 clamp 口径数字（22.46/20.14）换 min-max 未必更高
- 判断模型好坏**必须看 min-max 口径**；frame-diff 是绝对量纲下的，噪声指标看它
- 已把 overfit.py 改成双口径报告
