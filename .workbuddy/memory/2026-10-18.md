## ★★★ 根因（终于找到「全是噪声」的字面成因）

**`cond_init.py` 的 `to_phase`/`to_amp` 只输出 `n_osc=6144` 个值，
reshape 成 `[B,N,1]` 后广播到全部 D=125 通道。实测广播后跨通道

## 教训

- 「修复了表达通路」≠「能学到东西」。两者必须分别验证：
  先用秒级脚本验「能表达」（组间差异>0），再用秒级脚本验「学得动」
  （cos 对齐上升、梯度不衰减），最后才投长训练。
- **标量监督 vs 向量目标**：supervise 拿 target 相位的加权圆均值当目标
  （单方向），却只给模型一个标量输出。这类量纲/维度错配要一开始就查。

## 核心发现：梯度质量随「离 loss 的距离」衰减

```
block0~7   块内跨步余弦 ≈ 0.00     → 纯随机游走
block8     +0.368
block9     +0.627
block10    +0.652
block11    +0.650
```

机制：前向的 Kuramoto/drift 是混沌非线性动力学，梯度每穿过一层就被
洗掉一点方向。贴近 loss 的 block 梯度健康；穿过 8~11 层反向传播后
方向彻底随机。

**推论：block 0~7 的更新从头到尾只在破坏已学到的前向变换，没有学到任何东西。**

## 踩坑记录

1. **`nn.Module` 上挂 dict 属性不可靠**：`m._grad_masks = {}` + 以 Parameter 作
   key，实测 `getattr(m,"_grad_masks",{})` 拿到空 dict，掩码静默失效，
   三组结果完全相同却看起来"有输出"。修法：模块级全局 dict + 字符串 key + 断言。
2. **`w1` 的梯度空间不是独立的**：`w1.grad = xᵀ·δ`，而 δ 已被掩码限定在 w2 的
   相位行 → w1 梯度是 w2 相位行的确定性线性函数。所以「只训相位头输出层」和
   「只训相位头+w1」两组余弦**必然相等**（都是 +0.0526）。这是数学必然不是 bug，
   测的时候别当异常。
3. **`w2.weight[-D:,:].requires_grad_(True)` 这种切片视图**会作用到整个张量，
   导致按 `p.grad is not None` 筛出的 grads 列表为空。改用掩码而非切片。

## 第二十六死穴：条件通路**无法区分素材**（生成全是噪声的深层成因）
### 定位过程（三次自我纠错，方法论价值高）
1. **现象**：perband5/6 训练日志里 `dθcos` 全程精确 **+1.000**。
   该指标 =两素材在同一条件下的 dtheta 余弦 = **「条件通路能否区分素材」**。
   `+1.000` = 输出与素材无关的**通用场**。我一开始读反成「学得好」，是错的。
2. **误判①**：`diag_cond_discriminability.py` 显示 proj cos=0.984，
   断言「proj 层抹掉区分度」。→ 真，但只测到中间层，不是终点。
3. **误判②**：`diag_cond_layerwise.py` 里 proj 只有 4 层（index 0~3），
   我写了 `proj[4]`（不存在）拿到 cos=0.987，误判「SiLU 杀死了区分度」。
   修：索引改正后重测，**SiLU 只贡献 +0.02，跳跃在 proj[2] Linear2**。
4. **误判③**：`diag_proj_tail_act.py` 用**随机权重**做五种激活对照，
   五种 cos 全= 0.98582（完全相同）⇒ 对照设计无效（随机 Linear 本就把
   任何输入映到近同方向）。**教训：结构消融必须用真实训练权重。**
5. **误判④**：`diag_proj_tail_act2.py` 在真实权重下测到末端 SiLU 后 cos=0.595
   （区分度保留）⇒ 「换激活无效」的结论也是错的（测在错误的段上）。

| to_phase[1] 升维 | 1.0000 |
| dtheta 最终 | 0.9987 |
-五种尾部激活替换（SiLU/Tanh/ReLU/LayerNorm/零均值归一）在**正确位置**测：
  h 的 cos 全在 0.97~0.99 ⇒ **换激活一律无效**，投影层本身已塌。
- 低秩段只再吃 3%，**是无辜的**。
### 为什么 supervise 修不了
supervise 只要求「对齐某个 target 的方向场」，而两素材 target 主导方向
高度相似（都是「一张图的大致布局」）⇒ 输出**一个折中通用场**就能降 loss，
**区分素材从来不是必要条件**。

### v1/v2/v3 判别损失迭代
- **v1**（方向 hinge `relu(cos(d0,dir)−cos(d1,dir)−0.30)`）：disc 全程 0.0000
  = 恒在死区 = **梯度为零 = 没加**。根因：与 supervise 功率加权口径不同标度。
- **v2**（直接量`relu(cos(d0,d1)−0.60)`）：有梯度了，但 3000 步 cos 仍≈1.0
  （disc 顶格 0.4）。根因：**梯度要穿 R=16 低秩瓶颈才到 proj，
  压力被稀释 32 倍**。
- **v3**（★ 修法：判别项**直接加在 proj 输出 h 上**，梯度直达 proj）：
  | 步 | cos_h | cos_dθ |
  |---|---|---|
  | 1 | +0.9854 | 0（零初始化）|
  | 50 | +0.4413 | −0.4404 |
  | 600 | **−0.0542** | −0.9998 |
  ⇒ 条件通路**终于能分开素材**。但 dθ 判别项过压 → cos_dθ=−0.9998 反相关，
  下一步需让 h 项主导、dθ 项收紧（否则重建会崩）。
- 铁律新增：**「结构消融/激活函数对照」必须用真实训练权重 + 逐段实测，
  随机权重下的对照一律无效**（五种激活 cos 完全相同 = 对照设计坏了）。
- 铁律新增：**只作用在最终输出上的损失，穿过低秩瓶颈后到达上游会衰减几十倍**。
  要修上游表示，损失必须直接加在上游张量上。

  - 下一环：条件已分开，为何分开的是「通用场」而非「各自素材的场」？
    嫌疑= supervise 的 target 方向场两素材高度相似（都是"一张图的大致布局"），

## ★★★ 第二十七死穴（根因）：**dθ 幅度差4 倍，搬不动随机初态**
### 我先证伪了自己的两个假设
1. **「supervise 口径让两素材不可分」—— 证伪**
   `diag_target_dir_sim.py`：target 方向场两素材 cos = **−0.049**（几乎正交），
   幅度场 cos = −0.070。**素材信息在 target 里完整保留**，判别空间极大。
2. **「物理栈把结构洗成棋盘格」—— 证伪**
   `diag_stack_layerwise.py`（真实 ckpt，逐块 forward，12 块）：
   | 块 | 空间std | cos(θ,target) |
   |---|---|---|
   | init | 1.9726 | +0.0007 |
   | 6| 2.1040 | −0.0067 |
   | 12 | 2.3920 | **−0.0266** |
   空间std 不降反升，结构健康。物理栈**忠实演化，没破坏结构**。
   频率分布 w13-24 从 0.60 降到 0.43（自己在压高频），也不是棋盘格成因。
   ⇒ 物理栈**无罪**。它是忠实执行者，输入什么就演化什么。

### ★ 真凶：θ0 是均匀随机，dθ 是加性微扰，幅度差 4 倍
  实测（C:/Python312 一次跑出）：
  - 随机 θ0 与 target 的 cos = **0.00004**（完全无关）
  - 若 dθ = 0.5 × 理想相位差 → cos = **+0.4877**
  - 若 dθ = 1.0 × 理想相位差 → cos = +0.3733
  - 实测 |dθ| = **0.77**，而理想相位差尺度 ≈ π ≈ 3.14
  ⇒ **dθ 幅度差 4 倍，物理上搬不动随机初态到 target**
  ⇒ 所以 cos(θ,tar) 12 层只从 0.0007 走到 −0.0266，
     模型在忠实地演化一个「与 target 无关的随机场」
  ⇒ 随机场经12 层 Kuramoto 演化后自然收敛到**全同步**
     ⇒ 全同步 = 均匀场 = 解码出规则棋盘格。**棋盘格是「随机+同步」的结果，
     不是任何 bug 的直接产物。**
  - 频谱佐证：w13-24 能量占 0.60（素材应<0.05）⇒ 高频爆= 随机场的白噪声指纹
### 修法方向（下一轮）
  1. `phase_scale` 从 0.785 提到 **π 量级**（当前差 4 倍）
  2. 相位监督从「对齐方向场」改成**直接对齐 target 相位**（强得多）
  3. 重新审视 arctan 值域：arctan 输出 ±1，×2/π 后 ±0.636，
     ×phase_scale 0.785 → ±0.50，**天花板太低**，与 π 量级需求差 6 倍
### ★ 方法论铁律（三条，本轮最 valuable 的产出）
  1. **「指标不动」的第一个反问必须是「它到底在不在朝目标走」**。
     cos(θ,target)=−0.0266 这一行，本可以第一眼就否掉「物理栈洗结构」，
     我却先做了三层频率分析才回头看它。
  2. **加性调制必须有量级对账**：`θ0` 是 O(π) 量级的随机量，
     往它上面加一个 O(1) 的微扰，等于没加。
     凡「加性注入」都要先算 目标量级 vs 注入量级。
  3. **棋盘格/规则纹理 = 随机场 + 全同步的必然产物**，
     不是独立 bug。看到规则纹理先问「这是不是全同步」。

## 第二十七死穴修复落地：phabs500 结果
### 三处代码改动
1. `cond_init.__init__`: `phase_scale` 默认 0.785(π/4) → **π/2**，且可用
   `PHASE_SCALE` 环境变量覆盖。旧默认值的注释理由（「顶满 π 导致区分度
   丢失」）是**第二十六死穴的症状被误当成 dθ 该小的理由**——治标反伤本。
2. `CondInitModulator.supervise` 新增 `abs_w` + `theta0` 参数：
   直接监督 `θ0 + dθ ≈ θ_tar` 的相位差 MSE（w_norm 归一、去 DC）。
   **这是唯一对|dθ| 幅度产生真实压力的项**——原方向场loss 对幅度无要求
   （dθ=0.1×理想差 与 1.0×理想差 的 loss 几乎相同）⇒ 幅度永不自己长。
3. `aether_gif_model.forward`: `diag["theta0"] = theta0_m`
   （θ0 是每次前向重采的随机量，训练侧必须拿**同一个**，不能自己重采）
4. `overfit_cond3.py`: 新增 `PH_ABS_W`，预热与主循环都传 theta0

## phabs2k（2000 步续训）结果：**过压，退步** —— PH_ABS_W 不能贪

### 训练指标确实暴涨（看起来是成功）
| 指标 | phabs500 | phabs2k |
|---|---|---|
| wcos | +0.2525 | **+0.8547**（3.4×）|
| phase loss | 1.99 | **0.399**（降 5×）|
| hi/lo | 26.95 | **0.52~2.12** |
### 但视觉**退步**了：生成图变成近乎均匀的灰白噪点
| 绝对指标 | phabs500 | phabs2k | 素材 |
|---|---|---|---|
| PSNR | 13.20 | 12.49 | 噪声基线 13.03 |
| ac1 | +0.355 | +0.586 | +0.666 |
| sobel | 11.91 | **37.49（爆）** | 6.97 |

- `ac1` 又在骗人：这次是靠「**全图偏灰**」拿到的（均匀场也有低频），
  图像内容依然为零。**ac1 第二次被同一个陷阱骗到。**
### 根因：PH_ABS_W 过压
  绝对相位项是 `w_norm · MSE(相位差)`，**无上界**。
  w_norm 已做逐通道归一（量级 O(1)），MSE 在相位学不好时是 O(π²)≈10。
  权重 8 ⇒该项量级 ~80，直接压垮 amp(0.0064)/hi-lo 等所有项。
  证据：训练日志 `gen=13.56`（绝对相位项爆炸）而 `amp` 只有 0.0064。
### ★★ 铁律（新增，与第十八死穴同源但更隐蔽）
  **「指标暴涨 + 视觉退步」= 某个 loss 项被过度加权压垮了其余项。**
  判据：`gen`（supervise）量级 vs `amp` 量级差 3 个数量级 = 已失衡。
  加权 loss 必须**逐项量级对账**，不能只看总 loss 下降。
  权重不是越大越好：**3.0 有效，8.0 压垮**。
