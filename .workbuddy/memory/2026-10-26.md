### 三个可直接借鉴的技术（已写进方案）

**① Genie 的 Latent Action Model（解决"没有动作标签"）**
- Genie 用 **3 万小时游戏视频、零动作标签**，隐动作空间仅 **8 个离散值**
- 做法：从帧对 `(z_t, z_{t+1})` 无监督推断"什么动作导致了转换"
- **对本项目是救命方案**：GIF 没有控制信号，LAM 让这问题消失
- **物理化改造**：动作不做成离散 token，而是**加在 Kuramoto 上的外力场** `B_ctrl(u)`
  - 优势：可解释、可外推（Genie 的 token 无法说明"这个动作是什么"）

**② Dreamer 4 的 Shortcut Forcing（解决 rollout 慢）**
- 把"信号水平 τ"和"步长 d"作为条件输入，网络知道"这一步要跨多大"，K=4 步出帧
- **对本项目**：12 层递推现在是固定小步，rollout 100 步要 1200 次层计算
- 改造：层索引 t 与步长 d 解耦，让 12 层直接对应"跳几步"

**③ Dreamer 4 的稳定性六条（已验证的坑）**
- **EMA 必须**（扩散/流推理必须用 EMA 权重，当前项目无 EMA）
- **精度边界**：参数保持 fp32，**BF16 只用于 matmul 输入**，归一化与输出头用 fp32
  → 比我们"完全不能用 fp16"的结论更精细：**可以 BF16 matmul，不能 BF16 参数**
- **逆模型正则**：从 latent 反推 action，防止"预测下一帧=当前帧"的捷径
  → **这与当前模式坍塌是同一病灶**（模型用平均解拿低 loss）

### 物理版世界模型设计要点

| 模块 | 设计 |
|---|---|
| 状态 | 沿用 `(a, θ)` 物理量（相对黑箱 embedding 的结构性优势） |
| 动作 | LAM 无监督 + `B_ctrl(u)` 力场注入 |
| 转移 | **从"条件→全片"改为"状态→下一状态"**（生成器 → 模拟器） |
| 长期稳定 | **能量守恒 `U=−ΣWcos(θ_j−θ_i)` + 阻尼 + 序参量 r 平滑**（可测量，优于 loss 硬压） |
| 损失 | `L_pred + L_inverse(防捷径) + L_energy(守恒) + L_action_ctrl(可控性)` |

**本架构相对主流的唯一差异化**：用显式物理约束换数据效率（数据量少 1000 倍时靠归纳偏置达到可用精度）。**此命题尚未验证，是唯一值得下注的理由。**

### 最小可验证实验（建议第一个做）

```
数据：22 个 GIF 中挑 3 个有明确运动的（8ball 滚动 / senpai 挥手 / idolmaster 摆动）
1. 训 LAM（3 个视频，帧对 → 8 维隐动作）
2. 用 LAM 的 u 训 B_ctrl 注入
3. 固定初始帧，给差异最大的两个隐动作，各 rollout 5 步

判据：
  · 两条轨迹相位场 L2 距离 > 阈值
  · 且多次采样方差小（稳定）
```
**4GB 卡 + 现有数据 + 约 1 周可完成。失败则说明架构不具备动作可控性，世界模型路线需重新设计。**
