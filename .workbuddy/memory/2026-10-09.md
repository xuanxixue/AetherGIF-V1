### 物理通路：漂移场 + 正磁场（用户点名的架构死穴）
诊断发现 loss 贴随机地板（cos(θ−θ_tar)=0.0026、corr(a,a_tar)=0.0086，训练 6 轮不变）。分解 dθ 各通路量级定位：

| 通路 | 修复前 | 修复后 |
|---|---|---|
| 正磁场 coupling_struct | 131–2012（失控） | 4.0–6.2 |
| 漂移场 κ·g | 1.8–38（被淹没） | 5.1–62.8（反超） |
| dt·\|dθ\| | 最高 200 rad/块 | 4.0–4.9 |

三个根因，逐一修：
1. **漂移场退化**：旧实现 `g=V[虚部]`，但模型 a≈0.75 vs target a≈0.008 相差 90 倍，未归一化距离被 ‖z_i‖² 主导、softmax 退化均匀，吸引场变成"拉向原点"，target 相位信息完全进不了相位演化。改为**相位空间漂移**：权重用 L2 归一化复值场距离（等价相位余弦距离，消除幅度失配），力用 `sin(θ_j^tar−θ_i)`（周期有界）。新增 `softmax_kernel_phase`，分块框架复用
2. **ω 每次前向随机重采样**：ω 是系统固有属性而非初始状态，随机 ω = 每次换一个动力系统，无法学习。改为时空坐标×通道索引的**确定性准随机场** `_init_omega`
3. **空间尺度失配**：s_coord 归一化到 [0,1]，但 λ_s=3 按格子单位标定，32×32 网格相邻间距仅 1/31，exp(−3·0.001)≈1，耦合矩阵退化全 1、行和≈1000。乘 `(grid−1)²` 换算回格子单位

修完**零训练单次前向** cos(θ−θ_tar) 从 0.0042 → **0.7743**，|err| 中位 1.56→0.254 rad。

### 过拟合验证：振幅结构性锁死（第四个死穴）

200 步单样本过拟合（8-ball，lr=3e-4）实测：a_out 0.7546→0.7282（200 步只动 3.5%，target 0.195），phase loss 1.975→1.982 纹丝不动，PSNR 15.61→15.97 dB，frame-diff 11.22（噪声抖动）vs target 5.56。

**根因：`block.py` 的 `a_new = F.softplus(self.norm_a(a + ffn_out))`**
1. **量级锁死**：LayerNorm 永远输出均值0方差1，softplus 后均值必在 0.7–0.75，target 的 0.195 永远够不着
2. **重尾抹平**：LayerNorm 每个 (n) 位置独立归一化 64 个通道，把 FFT 幅度的重尾结构（std/mean≈5.75）强行均匀化
3. **梯度消失**：压到 a≈0.001 需 softplus(−7)，梯度仅 0.0009，小幅度系数学不动

**修复：log 域乘性残差** `a_new = a * exp(clamp(ffn_out, −6, 3))`，删掉 norm_a。FFT 幅度跨数量级，乘性更新让梯度在对数尺度均匀（0.75→0.001 只是 ln 尺度 −6.6 位移）。同时 `a0` 改 `exp(randn·0.8−2.5)` 量级匹配。冒烟验证：a_out 跨 0.004→2.5 重尾恢复，12 层堆叠数值稳定，a-grad 6/7 finite。

重跑 200 步：amp loss 0.33→**0.08**（降 76%），a_out 0.75→0.10（与 target 同阶）。但 PSNR 崩到 4 dB、frame-diff 0.03（静态图），phase loss 仍不动。

### 相位诊断：噪声相位污染（第五个死穴）

`scripts/diag_phase.py` 四层证据：
- **a_tar 分布**：p10=p25=0.0000，p50=0.0015，**69.4% 系数幅度<0.01**，79.8%<0.05。这些位置的 θ_tar=atan2(im,re) 是**纯数值噪声相位**
- **分层 cos**：<0.01 → +0.14（伪对齐）｜0.01–0.05 → +0.0002（纯随机）｜0.05–0.20 → **−0.017（排斥）**｜0.2–1.0 → +0.097｜>1.0 → +0.27
- **逐 block cos**：b0=+0.005→b11=+0.111 单调升但极弱（吸引方向对、力量不足）
- **正磁场 r**：0.012→0.459，同步在建立但未完成

**根因**：phase loss 对全部 N×D 位置平等 MSE，69.4% 的监督对象是 atan2 数值噪声，随机相位误差的梯度互相抵消、淹没有效位置 → 200 步 cos 纹丝不动。

**修复**：相位按 FFT 功率加权 `w=a_tar²`，`loss_ph = Σ(w·pe²)/Σw`。监控升级加 wcos（功率加权 cos）与 cos_eff（a_tar>1 桶）。

### 梯度诊断：相位核心零参数（第六个死穴）

`scripts/diag_grad.py` 分参数组测 phase loss 梯度 norm：

| 参数组 | grad_norm |
|---|---|
| omega_bias_head | 7.9e1 ~ 5.8e2（巨大）|
| kappa_scale_head | 2.5e1 ~ 4.0e2（巨大）|
| **drift_field** | **0** |
| **kuramoto** | **0** |
| **time_field** | **0** |
| T_scale_head / drift_target_head | 0 |
| ffn | 1e-2 ~ 2.5e-1 |

**根因**：DriftField / KuramotoSync / MeanFieldCoupling 全是**零参数结构先验**（Toeplitz 核、softmax 相位吸引），物理核心没有任何可训练参数。`dθ = ω + struct + mf + κ·g` 里唯一能训练改变相位的只有 ω 偏移与 κ 缩放两个弱自由度（T_scale 因 Langevin 默认关而恒为 0；time_field 的 natural_freq 被 `drive_freq` 内的 `with torch.no_grad()` 切断）。梯度巨大却 loss 不降 = 相位空间狂奔找不到最小值。

对照 UN-0（Unconventional AI，Naveen Rao）：明确"耦合矩阵 K 是最主要可学习参数"，AetherGIF 的耦合是零参数先验——这是架构层面核心差距。但零 Transformer/注意力约束禁止全可学习 K[N,N]，故走另一条物理化路线。

### 修复：驻波 FFN 输出复值残差，同时驱动振幅与相位

物理上共振传递函数是复值 `|H(ω)|·e^{iφ(ω)}`，既改幅度也改相位；此前 FFN 只输出振幅残差。改 `StandingWaveFFN.w2`：`Linear(hidden, D)` → `Linear(hidden, 2D)`，输出 chunk 成 (log_res, ph_res)。

`block.py`：
```
ffn_out = self.ffn(a, theta_new, ...)   # 在 Kuramoto 之后用新相位
log_res, ph_res = ffn_out.chunk(2, -1)
a_new = a * exp(log_res.clamp(-6, 3))
theta_new = theta_new + ph_res.clamp(-0.5, 0.5)   # ±π 太宽会动画抖动
theta_new = fold(theta_new)
```
加 `nn.init.zeros_(w2.weight/bias)`：初始残差=0，相位完全由 Kuramoto 决定，FFN 从恒等出发学修正。

冒烟验证：**th-grad 1/7 → 7/7 finite**，12 层稳定。
200 步实测：phase loss 1.87→**1.36**（首次实质下降），wcos 0.43→**0.54**，PSNR 7.50→**15.42 dB**，a_out 0.115→0.135 向 target 0.195 靠。

### 四次振幅 loss 方案对照（1000 步同 seed 同 lr）

**权重分布必须先算再上**（关键教训）：

- `a_tar^0.5`：低频 1.89 / 中低 0.99 / 中高 0.48 / 高频 0.64 → 温和，方向正确
- `a_tar^1.0`：低频 2.94 / 中高 0.13 → 又过头

**log1p 的尺度偏置**（`log1p(x)≈x` 对小 x，给的是绝对误差不是相对误差）：
ch10(a=0.02→0.05, 5×相对误差) loss≈0.04；DC(a=7.84→5.0, 1.36×相对误差) loss≈0.18。
**DC 一个小相对误差的 loss 是小通道大相对误差的 4.5 倍** → 小通道过度预测压不下来。

**纯 log 域失败的机理**（不是尺度问题，是优化路径问题）：
log 对 3.1× 惩罚(1.31) 确实远重于 log1p(0.017)，但 log 域梯度对所有通道等强，
**低频学准后梯度趋零，剩余梯度继续推高频往上走**（"低频饱和→高频补偿"），
ch16-63 ratio 达 3.19×，frame-diff 15.40 严重过冲。
