## 一、核心叙事：把「注意」换成「共振」，把「层」换成「时间」

整部片子只有一句话贯穿：**这套模型没有 self-attention，它用物理替掉了注意力。**

全片围绕两次「替换」展开：

| 传统 Transformer 组件 | AetherGIF 的物理替代 | 卡片 |
|---|---|---|
| Self-Attention（谁该关注谁） | Kuramoto 同步（谁的相位该被谁拉动） | 07 |
| FFN（通道混合） | 洛伦兹共振（扫频穿过谁，谁被放大） | 08 |
| LayerNorm（归一化） | OU 恢复力（log 域乘性更新 + 回归力） | 09 |
| 位置编码 | 3D 驻波调制 | 08 |
| 堆层深度 | 物理时间（耦合课程 / 温度退火 / 频率扫频） | 10 |

**为什么这个替换值得讲？** 因为它把「架构设计」变成了「物理建模」。当 attention 换成同步、相位耦合后，模型里所有的结构性和非线性都来自物理，而可训练参数被压到 202 万——连同"编解码器是架构一部分"这个教训一起，构成一套可迁移的工程方法论。

## 四、视觉系统

**规格**：全部 1920×1080（16:9），`viewBox="0 0 1920 1080"`，可直接录屏或二次剪辑。

**色彩**
| 用途 | 色值 |
|---|---|
| 主强调（青） | `#2DD4F0` |
| 次强调（紫） | `#C084FC` |
| 数据/警示（琥珀） | `#FBBF24` |
| 正向（绿） | `#34D399` |
| 负向（红） | `#FB7185` |
| 底色 | `#04060D → #0A0F1E` 渐变 |

**字体**：中文 `PingFang SC / Microsoft YaHei / Noto Sans SC`；数字与公式 `JetBrains Mono / Cascadia Mono / Consolas`（等宽，指标不跳动）。

**特效层**（每张卡共享）
1. 三团缓慢漂移的极光径向渐变（`mix-blend-mode: screen`）
2. 胶片颗粒（`feTurbulence` + overlay）
3. 四角 HUD 括号
4. 顶部一道极光扫描光带
5. 斜向流光（sheen）缓慢扫过
6. 暗角 vignette

**动效技术**
- CSS `@keyframes` 负责入场（slideIn / popIn）、漂移、辉光脉冲、流光
- SMIL `<animateTransform>` 负责里程表式滚动数字
- SMIL `<animateTransform>` + `clipPath` 负责数字轮盘
- 所有循环动画时长对齐到 3.6 / 5.2 / 6 / 7s 四档，便于剪辑时统一节拍

## 六、源码与重新生成

```
v3600_方案D_D125/
├── cards/            18 张成品 SVG（可直接用）
├── src/
│   ├── deck.py       视觉套件：配色、滤镜、组件、动画类
│   ├── cards_a.py    卡片 01-05
│   ├── cards_b.py    卡片 06-11
│   ├── cards_c.py    卡片 12-18
│   ├── build.py      构建入口 + 画廊生成
│   ├── studio.py     录屏播放器生成
│   └── shot.py       Edge headless 截图（视觉验收用）
├── index.html        画廊
└── studio.html       录屏模式
```

**重新生成全部卡片**
```bash
cd src
python build.py     # → cards/*.svg + index.html
python studio.py    # → studio.html
```

**改文案 / 调数值**：直接编辑 `cards_a/b/c.py` 里对应 `card_XX()` 函数里的文本与数据，重新 `build.py` 即可。所有硬编码数字都直接写在函数内，方便与报告对照。

**视觉自检**
```bash
python shot.py      # 全部卡片 → _shots/*.png
```
`shot.py` 会向 SVG 注入一段冻结样式的 CSS，让所有动画停在终态，截图即为最终排版效果，用于快速检查溢出/重叠。

## 七、内容准确性守则

1. **不夸大**。全片明确这是"单样本过拟合实验"，不是通用视频模型。卡片 01、17、18 都设置了这条边界。
2. **数字全部来自报告原文**，无估算、无杜撰。对比 v2500 时明确标注"训练片段不同，像素 PSNR 不可直接比"。
3. **失败模式照实讲**。卡片 09 讲方案 D 的 γ 一身二职与 log/log1p 域不一致；卡片 13 讲 v3500 曾对着伪影白干；卡片 15 讲未加权余弦反而下降（并解释这是好事）。这些反直觉点恰恰是科普的价值所在。
4. **不隐藏 codec 的重要性**。卡片 12、13 专门用两幕讲"编解码器是架构的一部分"，这是整个 v3600 最重要的工程教训。
5. **保留「均值指标会骗人」**（卡片 15、16）。这条对任何做生成模型的观众都有直接迁移价值。
