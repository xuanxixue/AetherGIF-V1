物理矩阵神经网络（PMNN）通用底层架构设计

版本 V0.1 · 2026-09-11 · 面向 V6 物理振子视频生成项目 · 六扩展（ELF / 漂移场 / UN-0 相位 / 热力学熵 / 共振驻波 / 时间物理）统一方案

0. 定位一句话

把 Transformer 的「token + 注意力（统计亲和）」换成「复值振子场 + 相位同步（物理耦合）」，深度方向改为物理时间 ODE，输出层改为 ELF 式连续去噪轨迹——得到一套模态无关、与 Transformer 同构地位的通用底层。任何模态先「振子化」进入连续嵌入场，经 R 轮物理块演化，最后一步离散化回符号。

2. 统一状态表示：正子因子 = 复值场元素

z_i = a_i ⊙ e^(iθ_i) ∈ ℂ^d   |   Z = (A, Θ) ∈ ℝ^(N×d) × ℝ^(N×d)
  • ai ∈ ℝd+：振幅向量（能量/置信度，保留个体信息——防全同步坍缩的关键通道）；
  • θi ∈ ℝd：相位向量（信息整合的载体，由耦合动力学演化）；
  • N：振子数 = 序列长度（token/patch/帧）；d：通道数（场深度）。

复化（从任意模态嵌入 ei 进入）：ai = softplus(Waei+ba)，θi = Wθei mod 2π。模态无关：文本 token、图像 patch、视频时空 patch、音频帧一律走同一入口。

3. 物理块（Physical Block）：与 Transformer Block 对位的通用层

R 轮物理块堆叠 = Transformer 的层堆叠。每块四层：

3.1 相位同步层（Kuramoto 耦合 · 替代注意力）· 对应扩展三

dθ_i^ν / dt = ω_i^ν + Σ_j W_ij · sin(θ_j^ν − θ_i^ν) + κ(t)·g_i^ν
  • ωiν：固有频率（输入驱动，每振子每通道）；
  • W ∈ ℝN×N：耦合矩阵（可学习；低秩 W=UVᵀ、r=32，或 Toeplitz 距离结构——借鉴 UN-0 稀疏性结论）；
  • κ(t)：同步强度 = K 值（时间场 × 热力学），控制「混沌 ↔ 同步」相变；
  • gi：漂移场引导项（外部力，见 3.3）；
  • 序参量 r(t) = |(1/N)Σj e^(iθ_j)| ∈ [0,1]：r→1 全同步 = 信息整合完成；K 值通过 Kuramoto 临界耦合 κc 控制每块工作在探索（r≈0）还是决策（r≈1）区间。

计算量与注意力同阶：全耦合 O(N²·d)，结构化 W 降至 O(N·d·r)。

3.2 共振-驻波 FNN 层 · 对应扩展五

每轮 FNN 实现「频率选择性放大 + 位置调制」，细化漂移方向：

h = σ( W₂·( W₁·z + b₁ ) ⊙ sw(z, ω_d) + b₂ )
  • 共振增益（Lorentzian 频率选择性）：A(ω_d, ω_n) = 1 / √((ω_d² − ω_n²)² + (2γω_d)²)——驱动频率 ω_d（来自 K 值）接近某通道固有频率 ω_n 时该通道被放大；
  • 驻波调制（位置感知，振子序号 = 空间坐标）：SWm(p) = cos(km·p)，km=2πm/N——前向波与后向波叠加成驻波，节点/腹点结构作为位置基（物理版 RoPE）；
  • FNN 输出即「共振选择后的场」，逐轮细化 K 值给定的方向。

3.3 漂移场层 · 对应扩展二（按真实机制实现）

V(Z) = V⁺(Z) − λ·V⁻(Z)
V⁺ = Σ_k softmax_τ(−‖z_i − z_k^tar‖²)·(z_k^tar − z_i)  （真实样本吸引）
V⁻ = Σ_j softmax_τ(−‖z_i − z_j‖²)·(z_j − z_i)  （生成样本互斥，防坍缩）
  • 多温度 τ 求和取多尺度（沿用原论文）；损失形态 Ldrift = MSE(φ(x), stopgrad(φ(x)+V))；
  • 架构偏离（你的设定）：原论文漂移场只在训练期起作用、推理一步前向；本架构中每轮物理块重算漂移方向 vφ(Z,t)，把「训练期演化」变成「推理时实时演化」——保留该设定，并在 §11 标注其验证点。

3.4 热力学-熵层 · 对应扩展四

  • 能量（XY 模型哈密顿量）：U(Z) = −Σi,j Wij·cos(θj−θi)。关键恒等式：∂U/∂θi = Σj Wij·sin(θj−θi)——Kuramoto 的 sin 耦合正是 XY 能量的梯度，相位同步层本质是能量下降动力学（锁相 = 能量最小化）；
  • 熵：S(Z) = −Σi pi log pi，pi = softmax(ai)（振幅分布熵）；漂移场排斥项 V⁻ 即熵压 −T·∇S（防坍缩的正则化解释）；
  • 自由能：F = U − T·S；温度调度 T(t)（退火）：T(t) = T_max·(1−t)^p + T_min，t: 0→1 冷却；
  • 噪声注入（涨落-耗散）：η ~ N(0, 2T/Δt) 朗之万项，训练期/采样期控制探索量。

3.5 时间物理层 · 对应扩展六

  • 深度 = 物理时间：整个堆叠是 ODE dZ/dt = fφ(Z, t, K(t))，t ∈ [0,1]，用 Heun/RK4 积分（可逆 → 显存与深度无关）；
  • 时间反演对称：编码/理解 = 正向积分（t: 0→1，场同步）；生成 = 时间反演（高熵噪声态 → 低熵数据态，由 K 值驱动、系统开放导出熵）；
  • 时间场：提供全局时间坐标与驱动协议曲线 κ(t)、T(t)、ω_d(t)（见 §7）。

5. 统一状态方程（六扩展合流的核心矩阵公式）

dZ/dt = M_κ(t)·Z + ∇_Z[ −U(Z) + T(t)·S(Z) ] + v_φ(Z, t) + η(t)
  • Mκ(t)·Z：K 值导航的线性矩阵算子（时间场 × 热力学 → κ(t)；内含耦合强度缩放、频率选择矩阵、漂移线性部分）——这是你要的「矩阵公式」的线性主轴；
  • ∇Z[−U + T·S]：物理势能下降 + 熵压。由于 U = −ΣWijcos(θj−θi)，该项自动展开出 Kuramoto sin 耦合（扩展三）、自由能动力学（扩展四）、漂移排斥项（扩展二）——三个扩展在同一个梯度项里合流；
  • vφ(Z,t)：漂移场学习残差（扩展二，推理时逐轮活跃）；
  • η(t)：朗之万噪声（温度注入，涨落-耗散，扩展四）。

诚实标注：整体是「线性算子 + 非线性梯度项 + 学习残差 + 噪声」的混合动力学，不是纯线性矩阵公式——按真实机制组合，不假装全线性。

6. ELF 输出融合（扩展一）

  • 轨迹：物理核心不直接输出最终正子因子，而是输出连续嵌入空间的去噪轨迹 {xt}；插值 xt = t·x₁ + (1−t)x₀，x₀ ~ N(0,I)（整流流，与 ELF 一致）；
  • 条件信号：K 值方向（时间场 × 热力学给出的 κ(t)、ω_d(t)、T(t)）充当流匹配条件 c——比普通条件信号多了物理约束（同步度、温度、熵预算）的精确性；
  • 共享权重：物理核心即速度场网络 vθ(xt, t, c)，去噪与后续解码共用权重（ELF 同款）；
  • 正子解码网络双分支：
    • 去噪分支（t < t_dec）：继续轨迹细化/速度场预测；
    • 解码分支（t ≥ t_dec）：反嵌入矩阵 E ∈ ℝ^(d×V) 将连续嵌入投影回离散 token；
    • mode 门控：g(t) = σ(Wg·[t, r(t), κ(t)])，t_dec ≈ 0.98——你的「mode token 机制」落地为连续门控标量；
  • ELF 同款技巧：训练目标嵌入由冻结 T5 编码器生成（推理时丢弃编码器），轨迹空间用 128 维瓶颈。

7. 训练协议

  1. 总损失：L = Lfm + λ₁Lsync + λ₂Ldrift + λ₃LF
    • Lfm = E‖vθ(xt,t,c) − (x₁−x₀)‖²（流匹配速度匹配，ELF 主损失）；
    • Lsync = ‖r(t) − rtarget(t)‖²（序参量跟踪 K 课程）；
    • Ldrift = MSE(φ(x), stopgrad(φ(x)+V))（漂移场一致性，原论文损失）；
    • LF = U(Z) − T·S(Z)（自由能正则，热力学层）。
  2. K 课程：κ(t) 从弱到强（先混沌探索、后同步整合）——对应扩散噪声调度；κ(t) = κ_max·σ((t−t_c)/τ)（在 t_c 处发生同步相变）；
  3. 两阶段：阶段 A 在冻结编码器目标上预训练物理核心（同步 + 共振基 + 漂移场）；阶段 B 端到端流匹配微调（T 退火 + 噪声注入）；
  4. 数值：Heun/RK4 积分，可逆层 → 训练显存与深度无关。

8. 推理协议

  • 生成：x₀ ~ N(0,I) → ODE 正向积分 t: 0→1，每步物理块计算（同步 + 驻波 + 漂移场逐轮活跃）→ x₁ 干净嵌入 → t=1 解码分支反嵌入 → token；
  • 编码/理解：正向时间积分，场同步至 r→1 提取全局状态（表示 = 同步后的场）；
  • 模态扩展：视频 = 帧序列时空 patch → 时空振子场；时间物理层天然承载时间维度；轨迹作用于潜在嵌入（衔接 V6 的 480p/21:9 管线）。

11. 校准与风险（诚实标注）

  • 「非统计」的准确边界：去掉的是注意力机制与 token 级逐步交叉熵；流匹配与漂移场本质仍是分布建模（统计目标）。精确表述：机制是物理的，分布目标是统计的——两者不矛盾，也无需回避；
  • 「无人挑战」建议降级表述：ELF、Drifting、UN-0、Kuramoto 同步网络在 ML 均有先例，真正没有先例的是「模态无关物理矩阵通用底层」这一组合 + K 值导航 + 推理时漂移场活跃——组合是新的，组件不是；
  • 全同步坍缩（r→1 时个体信息同质化）：缓解 = 异质固有频率 ωi + 振幅通道保留个体信息 + 稀疏/局部耦合；
  • 连续空间训练不稳（ELF 已知痛点：嵌入分布与高斯噪声差异大）：缓解 = 128 维瓶颈 + 归一化 + K 课程；
  • ODE 数值误差累积：Heun/RK4 + 残差连接；
  • 漂移场推理时活跃 = 对原论文的有意偏离：需验证每轮一步「分布对齐」的稳定性与额外成本（×R）；
  • 许可：UN-0 权重 CC-BY-NC-4.0 非商用，商用需自实现 Kuramoto 层（本设计数学均为公开公式，无实现障碍）；
  • 「物理」的边界：热力学/共振/时间物理以可计算、可微、可测的数学算子进入（XY 能量、Lorentzian 共振、ODE 时间反演），是类比算子而非字面物理声明。

12. 与 V6 视频项目衔接

  • 该架构的模态无关性使其可直接作为视频生成骨干：帧序列 → 时空振子场 → 物理块演化 → 潜在嵌入轨迹 → 末步解码；
  • 时间物理层天然处理帧间时间维度，与你的物理振子视频生成路线同源；
  • 建议验证路径：先在文本/图像小规模验证（128 维瓶颈、CIFAR-10 级），重点测两项——① 同步层 R 轮内是否达到目标序参量 r(t)；② 漂移场推理时活跃是否优于训练期演化；通过后再上 480p/21:9 视频规格。
