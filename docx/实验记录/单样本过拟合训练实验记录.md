## 一、实验目的与判据

### 1.1 核心问题

PMNN 物理核（Kuramoto 振子 + 漂移场 + 驻波 FFN + 热力学）在**不使用任何 Transformer/注意力结构**的
硬约束下，能否直接生成出**可看、甚至能还原真实 GIF** 的画面？

### 1.2 为什么用单样本过拟合

| 维度 | 说明 |
|---|---|
| 排除数据问题 | 数据增强、多样性、分布不均全部剥离，唯一变量是模型能力 |
| 排除优化问题 | 1 个样本必然能被记住；若记不住，是架构/通路本身断了 |
| 定位瓶颈 | 单样本下仍存在的缺陷，一定是结构性的，不会被"多数据掩盖" |
| 成本 | batch=1，单次前向 ~1 秒，1000 步约 1 小时，可反复迭代 |

### 1.3 判据（达到什么算成功）

1. **PSNR** vs target-recon 天花板（当前 **26.70 dB**）差距在 3 dB 以内
2. **帧内对比度**（std）达到 target 的 90% 以上
3. **帧间变化**（frame-diff）接近 target，不能过冲也不能欠冲
4. **逐通道振幅比** 全部落在 0.8~1.2（谱形状正确）
5. **肉眼可辨认细节**（球上的数字、轮廓边界锐利）

## 二、实验设置

### 2.1 数据口径

```python
D, GRID, PATCH, WIN, IMG, TS = 64, 32, 4, 5, 128, 6
N = time_step × grid² = 6 × 32 × 32 = 6144
```

| 参数 | 值 | 说明 |
|---|---|---|
| GIF 输入 | `8-ball_1f3b1.gif` | 台球表情包，用户指定 |
| 分辨率 | 128×128 | |
| 帧数 | TS × WIN = 6×5 = 30 帧 | |
| 空间块 | PATCH=4×4，GRID=32×32 | 每块 4×4 像素 |
| 时空块 | WIN=5 帧 | |
| 编解码 | `rfft2(win, patch²·3)` → 取 D=64 个低频复系数 | 零参数、可逆 |

### 2.2 模型配置

```
AetherGIFModel  参数量 = 1,135,658（瘦身版，排除冻结 Qwen）
d_model = 64,  n_blocks = 12
PMNNCore = 12 × PhysicsBlock
PhysicsBlock = DriftField → KuramotoSync → StandingWaveFFN → Thermodynamics
```

**Qwen 绕过**（`use_qwen=False`）：
```python
# aether_gif_model.py
if use_qwen:
    self.qwen = QwenTextEncoder(...)
else:
    self.text_param = nn.Parameter(torch.randn(1, self.text_dim, device=device) * 0.02)
```
理由：Qwen 只为文生 GIF 服务，当前阶段只验证"能否重建"，不需要文本编码器。
绕过后可训练参数从数十亿降到 1.13M，显存干净，避免 SIGTERM。

### 2.3 训练参数

```python
LR = 3e-4
opt = torch.optim.AdamW(model.parameters(), lr=LR)
SEED_MODE = "fixed"     # 关键：固定初始条件 seed
AMP_P = 0.5             # 振幅 loss 软化权重幂次（R8 引入）
```

**fixed seed 为什么关键**：
- 每步重设 seed ⇒ a0/θ0 每步随机 ⇒ 模型必须学"任意起点→target"的全局吸引子
- 12 个 block 的演化深度（零训练 cos 仅 0.11，指数趋近需 ~300 步深度）**根本不够**
- 固定 seed ⇒ 只需记忆一条轨迹，先验证通路的记忆能力

### 2.4 Loss 定义（最终版）

```python
# 振幅：log1p 压重尾 + 软化功率权重
AMP_P = 0.5
a_max = a_tar.amax().clamp(min=1e-8)
w_amp = (a_tar / a_max).pow(AMP_P)
w_amp = w_amp / w_amp.mean().clamp(min=1e-8)
ae = (torch.log1p(a) - torch.log1p(a_tar)).pow(2)
loss_amp = (w_amp * ae).sum() / w_amp.numel()

# 相位：按 FFT 功率 a_tar² 加权
w_ph = (a_tar ** 2).clamp(min=1e-8)
pe = torch.remainder(th - th_tar + math.pi, 2 * math.pi) - math.pi
loss_ph = (w_ph * pe.pow(2)).sum() / w_ph.sum()

loss = loss_amp + loss_ph
```

## 四、实验时间线：八轮迭代

### R1 基线：振幅被 LayerNorm/softplus 锁死

**症状**：PSNR 15.97 dB，生成纯噪声动态，a_out 锁在 0.75（target 0.195）

**根因**：
```python
# 旧代码
self.norm_a = nn.LayerNorm(d_model)
a_new = F.softplus(self.norm_a(a + ffn_out))
```
- LayerNorm 输出恒均值 0 方差 1
- softplus 后 a 恒锁在 0.7~0.75
- 负区梯度消失，重尾被抹平

**修复**：改 log 域乘性演化
```python
log_a = torch.log(a.clamp(min=1e-8))
a_new = a_new * torch.exp(log_res.clamp(-6, 3))
```

**结果**：a_out 0.75 → 0.10 →（加 OU 后）0.1985 ≈ target 0.195 ✅

---

### R2 零参数物理核

**症状**：phase loss 完全不降，梯度巨大但 loss 纹丝不动

**根因（`diag_grad.py` 梯度诊断决定性证据）**：
```
drift_field   grad_norm = 0.000000  ← 恒为 0
kuramoto      grad_norm = 0.000000  ← 恒为 0
time_field    grad_norm = 0.000000  ← 恒为 0
```
`dθ = ω + struct + mf + κ·g` 中，DriftField / KuramotoSync / MeanFieldCoupling
全是**零参数结构先验**（Toeplitz 核、softmax 相位吸引），物理核心没有任何可训练参数。
唯一能训练改变相位的只有 ω 偏移与 κ 缩放两个弱自由度。

**对照 UN-0（Unconventional AI）**：明确"耦合矩阵 K 是最主要可学习参数"。
AetherGIF 的耦合是零参数先验 —— 这是架构层面核心差距。
但零 Transformer/注意力约束禁止全可学习 K[N,N]，故走物理化路线。

**修复：给驻波 FFN 加相位输出头**
```python
# 物理依据：共振传递函数是复值 |H(ω)|·e^{iφ(ω)}，既改幅度也改相位
self.w2 = nn.Linear(ffn_hidden, 2 * d_model)   # 原为 d_model
nn.init.zeros_(self.w2.weight)                  # 初始残差=0，从恒等出发
nn.init.zeros_(self.w2.bias)
# forward:
ffn_out = self.ffn(a, theta_new, omega_d, t_coord, s_coord)   # 在 Kuramoto 之后
log_res, ph_res = ffn_out.chunk(2, dim=-1)
```

**结果**：**phase loss 首次实质下降** 1.87 → 1.36，wcos 0.43 → 0.54

---

### R3 相位噪声主导梯度

**症状**：功率加权后 cos 仍卡 0.38

**根因**：**FFT 系数是极重尾分布**（8-ball 实测）

```
a_tar 中位数 = 0.0015
p90          = 0.18
p99          = 5.4
69.4% 系数幅度 < 0.01
```
这 69.4% 的系数，其 `θ_tar = atan2(im, re)` 是**纯数值噪声**（无监督意义）。
平等相位 MSE 会让随机相位误差的梯度淹没有效位置。

**修复**：
```python
w_ph = (a_tar ** 2).clamp(min=1e-8)
loss_ph = (w_ph * pe.pow(2)).sum() / w_ph.sum()
```

---

### R4 相位折叠与饱和

**症状**：frame-diff 14.7（帧间相位断裂）；clamp ±0.5 时 cos 钉在 0.416

**修复**：
```python
# 删除演化链中间的 remainder 折叠，θ 连续累积；仅在 loss 处做 remainder
# （下游全部用 sin/cos，天然周期，消除梯度断裂）
theta_new = theta_new + ph_res.clamp(-1.5, 1.5)
```

**软饱和（运算放大器物理）**：
```python
dtheta = self.omega_max * torch.tanh(dtheta / self.omega_max)   # omega_max = 8.0
```
Ω_max=2.0 时动画被杀死（frame-diff 0.24），提升到 8.0 恢复。

### R5 振幅爆炸与 OU 回复力

**症状**：a_out 爆到 100× target，decode 归一化被爆炸值主导，frame-diff 塌到 0.02

**根因**：log 域残差 clamp 太宽，12 层堆叠下 12 × e⁴ ≈ 溢出

**修复：Ornstein-Uhlenbeck 回复力（统计物理经典稳定化）**
```python
# 布朗运动 + 回复力，Fokker-Planck 稳态有界
self.a_gamma = nn.Parameter(torch.tensor(0.1))
self.a_mu = nn.Parameter(torch.tensor(math.log(0.2)))

log_a_new = log_a + res - self.a_gamma * (log_a - self.a_mu)
a_new = torch.exp(log_a_new.clamp(-20.0, 5.0))
```

**结果**：a_out 稳定 0.21，**frame-diff 从 0.02 恢复到 2.28** ✅，相位学习同时改善（0.472 vs 0.662）

---

### R6 漂移场空间平均上限

**症状**：cos 钉在 **0.4169** 到小数点后 4 位不动

**证伪实验**：
- κ 饱和曲线扫描 → 不是强度问题
- DirectDrift 对照实验 → 空间近邻平均上限 **0.42**，直接吸引达 **0.998**

**根因**：FFT 相位在空间上不光滑
```python
# 原式：空间 softmax 加权平均，上限 0.42
g_i = Σ_j softmax(空间距离_j) · sin(θ_j^tar − θ_i)

# 修复：叠加直接目标吸引分量
self.direct_weight = nn.Parameter(torch.tensor(1.0))
g = g + self.direct_weight * torch.sin(theta_tar - theta)
```

**结果**：cos 0.42 → **0.82** ✅

### R7 标量 OU 压平谱（第七死穴）

**用户反馈**："相比于之前好很多了，最起码能看出有那个表情包的那个运动轨迹了，但是吧，还是没有细节。"

#### 排查方向

用户猜测三个方向：**分块太小 / PSNR 有问题 / 步数太少**。逐项实测：

| 猜测 | 实测结论 |
|---|---|
| 分块太小 | ❌ **不是瓶颈**（见第五节，天花板 26.70 dB，d_model/patch 几乎无影响） |
| PSNR 口径 | ❌ 影响小（一致归一化 11.32 vs min-max 10.75，差 0.6 dB） |
| 步数太少 | ✅ **是一个因素**（500→1000 步 +5.6 dB），但不是主因 |

#### 真正根因

```python
# 旧代码：标量 OU 先验
self.a_mu = nn.Parameter(torch.tensor(math.log(0.2)))
```

**target 每通道振幅均值跨 727 倍**：

| 频段 | ch_mean min | median | max | mean |
|---|---|---|---|---|
| 低频 | 0.0235 | 0.0555 | **7.8399** | 0.5730 |
| 中低 | 0.0177 | 0.0474 | 0.8759 | 0.1215 |
| 中高 | 0.0108 | 0.0179 | 0.0637 | **0.0247** |
| 高频 | 0.0118 | 0.0302 | 0.4552 | 0.0613 |

标量 μ 把所有通道拉向同一个 a=0.2 →
- 中高频小通道被**抬高** ~8×
- 低频大通道被**压低**
- **整张谱被压平**

**决定性验证**：
```
预测振幅比（中高）= 0.2 / 0.0247 = 8.1×
实测振幅比（中高）=            8.3×      ← 精确吻合
```

#### 修复

```python
# per-channel OU 平衡点：谱包络成为一阶可学参数
self.a_mu = nn.Parameter(torch.full((d_model,), math.log(0.2)))
# dL/dμ_c = γ·dL/dlog_a —— 梯度路径仅 1 步，不必穿透 12 层 FFN 残差
# a_gamma 保持标量
```

#### 同口径 1000 步对照

| 指标 | 标量 μ | per-channel μ |
|---|---|---|
| PSNR（诚实 vs 诚实） | 16.97 dB | **17.60 dB** |
| profile_cos | ~0（结构上不可能） | **+0.913** |
| 模型逐通道跨度 | 1x | **171x**（target 727x） |
| wcos | 0.853 | 0.843 |
| checkpoint `a_mu` 逐通道 std | 0 | **0.0436** |

**图像域（直接回答用户"没细节"）**：

| 指标 | 标量 μ | per-channel μ | target |
|---|---|---|---|
| **帧内对比度** | **7.8** | **29.60** | 33.88（达成 **87%**） |

**用户反馈确认**："能看出球上的数字了" ✅

### R8 振幅 loss 尺度偏置（第八死穴）

**用户反馈**："细节上虽然说比那个多了，但是效果还是不行，想办法再提升提升可以吗？根本没有做到还原，还是很糊。"

#### 消融诊断：决定性实验

新建 `scripts/diag_blur.py`，把模型输出**分别替换成 target 分量**，看 PSNR 涨多少：

| 版本 | 当前 | 相位→target | 振幅→target | 结论 |
|---|---|---|---|---|
| per-channel μ 版 | 17.59 dB | **+0.07** | **+5.60** | 振幅是瓶颈 |
| log 域版（失败） | 11.14 dB | +0.32 | +10.53 | 振幅是瓶颈 |

**相位完全不是瓶颈**（仅 +0.07 dB）——此前对相位的担心是错的方向。

#### "糊"的机理

逐通道振幅比：

```
ch    target     model      比值
 0    7.8398    7.6433    0.97    ← DC 已学准
 1    0.2355    0.2246    0.95
 ...
10    0.0305    0.0584    1.91
11    0.0409    0.0586    1.43
12    0.0901    0.1236    1.37
13    0.0373    0.0599    1.61
14    0.0235    0.0570    2.43
15    0.0243    0.1039    4.28    ← 严重偏高
 ... (ch 16-63 平均) target=0.0692 model=0.0907 比值=1.31
```

**中低频被系统性抬高 → 该黑的地方不够黑 → 边缘被抹平 = "糊"**

#### 四次振幅 loss 方案对照

| 方案 | PSNR | 振幅比(低/中低/中高/高频) | a_out | 判定 |
|---|---|---|---|---|
| **A. log1p 无权重** | 17.60 | 1.4/2.0/3.2/2.2 | 0.211 | 基线 |

#### log1p 的尺度偏置（隐蔽陷阱）

`log1p(x) ≈ x` 对小 x 近线性，所以它给的是**绝对误差**而非相对误差：

```
ch10:  a_tar=0.02 → 输出 0.05   5.0 倍相对误差 → loss ≈ 0.04
DC:    a_tar=7.84 → 输出 5.0    1.36 倍相对误差 → loss ≈ 0.18
```

**DC 一个小相对误差的 loss 是小通道大相对误差的 4.5 倍** → 小通道过度预测压不下来。

#### 纯 log 域失败的机理（不是尺度问题）

log 对 3.1× 的惩罚（1.31）确实远重于 log1p（0.017），但：

> **log 域梯度对所有通道等强。低频学准后其梯度趋零，剩余梯度继续推高频往上走**
> （"低频饱和 → 高频补偿"），ch16-63 ratio 达 3.19×，frame-diff 15.40 严重过冲。

### 9.3 层级归因：根因是"层级/形状绑死"（第九个死穴）

诊断脚本 `diag_amp.py` 逐块分解 2500 步 checkpoint 的终态层级：

```

FFN 残差 r̄ 合计 : −0.899   ← r̄ 越界兼职，块 7-11 把 r̄ 推到 ±0.86（tanh 压顶）
a_mu span        : 0.06~0.11（target 6.589，谱形状根本没学）
终态层级        : 高出 target 1.87×
```

**根因链**（单 γ 的结构性矛盾）：
1. 旧的 `log a_new = (1−γ)log a + γμ + res` 里，**同一个 γ 同时控制层级收敛速率和形状衰减**，二者无法兼得——γ=0.3 时层级 12 块收敛 98.6% 但形状被压到 1.4%；γ 自学到 0.04 时初值层级残留 61% 洗不掉。
2. γ 可训练时，Adam 走"调小 γ 保留层级残留"的捷径，μ 被架空。
3. FFN 残差的通道均值 r̄ 与 μ 都能改层级（都是 1 步路径），梯度抄近路走 r̄，μ 学不动谱形状。

### 9.4 本轮修复（方案 F：正交分离 + 分组学习率）

**架构改动（`src/physics/block.py`）**：
1. **γ 拆成两个常量**：`a_gamma_lvl=0.5`（层级收敛，12 块后 0.5^12≈2e-4，初值彻底洗掉）、`a_gamma_shape=0.1`（形状记忆），均 `requires_grad=False`，堵死捷径。
2. **残差零均值**：`res = res − res.mean(dim=1)`，只含位置级形状，不含通道层级；数学上 `mean_pos(log_a_new) = m_new` 精确成立，层级对 res 的梯度严格为 0。
3. **层级/形状正交递推**：`m_new = m + γ_lvl·(μ−m)`，`δ_new = (1−γ_shape)·δ + res`。
4. **μ 在 block 间共享**（第十个死穴）：11 块各一个 μ 时，只有最后 1~2 块能收到有效梯度（贡献 ∝ γ_lvl(1−γ_lvl)^(11−i) 指数衰减），谱形状 span 卡在 0.1。共享一份 μ 让梯度沿线累加，谱包络成单参数直通路径。

**loss 改动（`scripts/overfit.py`）**：
5. **log 域相对误差**替代 log1p 绝对误差。此前方案 C 用 log 失败，是因为层级/形状绑死导致"低频饱和→高频补偿"串扰；正交分离后通道间层级动力学解耦，log 等强梯度不再引发串扰，反而让每个通道的 μ_c 拿到与 DC 等强的监督。这是 log 域能用的**前提**。

**优化器改动**：
6. **分组学习率**：`a_mu`（64 维低维凸参数）用 lr×100，其余参数保持 lr。这是谱形状从"几万步才铺开"到"150 步铺开"的关键开关。

### 9.6 AMP_P 权重的方向效应（方案 G 的由来）

150 步对照验证，发现 **(a_tar/a_max)^p 权重在 log 域是多余且有害的**：

| AMP_P | 频段比 | frame-diff | 判断 |
|---|---|---|---|
| 0.5 | 1.4/1.4/1.3/1.3（偏高） | 11.17（抖） | DC 偏置，高频监督不足 |
| 0.25 | 0.6/0.6/0.8/0.6（偏低） | 1.82（压死） | 同一偏置摊平后收敛过慢 |

**根因**：log 域 `(la−lt)` 已经是"倍数"度量，DC 与高频自动同尺度；再叠幅度权重等于重新按幅度占比给 DC 加权（p=0.5 时 DC 权重是高频 ~5.8 倍），μ_c 稳态被大通道主导。p 越小只是把偏置摊平、让 μ 收敛更慢。

### 9.7 方案 G（当前）：log 域无权重 + 软截断

```python
EPS_A = 0.01
la = torch.log(a.clamp(min=EPS_A))
lt = torch.log(a_tar.clamp(min=EPS_A))
loss_amp = (la - lt).pow(2).mean()   # 不加任何幅度权重
```

- `<0.01` 的近零系数（69.4%，功率≈0）误差自动归零，不污染梯度
- `≥0.01` 的有效系数在 log 域平等回归，μ_c 收敛到"有效系数的几何均值"
- 软截断比硬 mask 稳（硬 mask 会让整条高频通道没梯度、μ_c 停初值）

150 步验证：loss 12→2.8（比 F 的 12→10 降得快得多）、谱跨 1x→21x、a_out 一路降到 0.027（μ 从 −3 出发，150 步爬不完 DC 跨的 5 个 log 单位）。方向对，缺步数。μ lr 提至 ×80 跑 1000 步。

### 9.8 下一步方向

## 十、经验教训

### 10.1 方法论

1. **消融优先于猜测**。"很糊"至少有四个可能根因（表征/相位/振幅/步数），
   肉眼无法区分。消融让每个因素单独暴露自己的 dB 贡献 —— 本项目直接靠它发现
   相位只贡献 0.07 dB，避免了在相位上浪费大量时间。

2. **调 loss 前先算权重分布**。`a_tar²` 看起来物理合理（功率 ∝ 能量），
   实测让 DC 独占 99.9% 监督。任何加权方案都应先打印各通道的实际占比。

3. **150 步验证 > 1000 步赌博**。方案 B 跑偏时，若等 1000 步才发现，浪费 1 小时 GPU。
   150 步足以看出振幅比趋势。

4. **全局均值会骗人**。`a_out=0.211 ≈ target 0.195` 看似完美，
   但 `profile_cos ≈ 0`、中高 ratio 8.3×。必须看逐通道剖面。

5. **频域天花板必须调真实函数测**。手算漏一个标定常数（`z*10.0`）
   就让 PSNR 从 26.70 变成 14.84，结论完全反转。

### 10.2 物理架构

1. **零参数结构先验 = 无学习能力**。DriftField / KuramotoSync 全是零参数
   （Toeplitz 核、softmax 吸引），梯度诊断显示 grad_norm 恒为 0。
   对照 UN-0："耦合矩阵 K 是最主要可学习参数"。

2. **标量先验会压平重尾谱**。物理系统的平衡点不该是标量。
   FFT 振幅跨 727 倍时，标量 OU 先验是压平谱的直接原因。

3. **重尾分布只能用乘性演化**。LayerNorm/softplus（加性+归一）会抹平重尾。

4. **演化链不要中间折叠相位**。下游全用 sin/cos（天然周期），
   只在 loss 处做 remainder 即可，消除边界梯度断裂。

5. **统计物理的稳定化机制有效**：OU 回复力（布朗运动+回复力，Fokker-Planck 稳态有界）
   一次性解决了振幅爆炸（100×）和 frame-diff 塌陷（0.02 → 2.28）。

## 十一、第十一死穴：「方块」既不归高频过冲，也不归分块边界，而是 DC 通道能量垄断

### 11.1 问题回退

偶有震荡、对比度略异，但轨迹/残影/数字/配色全对。方案 F/G 修复后视觉反而更差。
按第十死穴方法论，先做离线消融分清「方块」与「糊」各归谁管，不动手改架构。

### 11.2 消融一：像素级（`scripts/diag_block.py`）

固定 clamp 口径，对 `ckpt_schemeG_1000.pt`：

| 方案 | PSNR | Δ | 亮度 | 对比度 | 帧间差 |
|---|---|---|---|---|---|
| 模型原样 | 17.66 | — | 77.9 | 32.1 | 5.84 |
| **振幅→target** | **24.10** | **+6.44** | 92.7 | 29.0 | 5.48 |

**结论：「糊」和「方块」都归振幅，不归相位（+0.34 dB 基本无效）。**
视觉对照（`cmp_ablation.png` 第 4 行）显示振幅→target 后网格感完全消失、球轮廓与

### 11.3 消融二：分块边界能量 —— 排除编解码层

误差**平方**能量在 patch 边界（每 4 像素）vs 块内部：

| 方案 | 边界能量 | 内部能量 | 比值 |
|---|---|---|---|
| 模型原样 | 1214 | 1226 | **0.990** |
| 振幅→target | 314 | 352 | 0.892 |
| 相位→target | 1101 | 1082 | 1.018 |

比值≈1.0，误差在边界与内部**均匀分布**，没有任何分块边界聚集。
**「方块」不是编解码/分块层的问题，架构层改不动它——因为它根本不在那里。**

> 踩坑记录：首版用带符号误差做边界统计，正负相消导致比值失真成 1e10 量级。
> 边界统计必须用平方能量。

### 11.4 消融三：真正的根因 —— DC 通道能量垄断（第十一死穴）

`diag_spec.py` 逐通道统计（rfft2 网格 3×25=75，d_model=64 覆盖 85.3%）：

```
sum(a_tar²) 前 5 通道能量占比 = 98.07%
target ch0（时间freq0,空间freq0）平均振幅 = 7.8398（其余通道 0.01~0.46）
模型 sum(model)/sum(target) = 1.100   能量比 = 1.872
过冲通道(>2×)：0/64
```

逐组替换实验（`scripts/diag_which_ch.py`，把该组模型振幅换成 target 振幅）：

| 替换组 | 通道数 | 该组振幅能量占比 | PSNR | 中频比 |
|---|---|---|---|---|
| （不替换） | — | — | 17.62 | 0.87 |
| **w=0 (DC)** | **3** | **99.4%** | **23.49** | 0.79 |
| w=1-2（低频） | 6 | 0.2% | 17.67 | 0.87 |
| w=3-6（中频） | 12 | 0.3% | 17.69 | 0.89 |
| w≥7（高频） | 43 | 0.2% | 17.65 | 0.88 |
| 全部→target | 64 | 100% | 24.22 | 0.82 |

**3 个 DC 通道独占 99.4% 振幅能量。只替换它们，PSNR 从 17.62 直跳 23.49；
替换其余 61 个通道合计只涨 0.1 dB。**

**「方块」的物理成因**：图像对比度 100% 由 DC 通道的振幅决定。模型对 DC 通道
振幅的预测误差，直接变成整帧的亮度/对比度偏差；这个偏差在每个 4×4 块上独立发生，
块与块之间无平滑约束 → 表现为**规则网格状明暗花纹**。所以：
- 不是"高频过冲"（过冲通道 0/64）
- 不是"分块边界"（边界能量比 0.990）
- 而是 **DC 通道（块内均值）预测不准 + 块间无平滑**，视觉上投影成网格

**「糊」的成因**：DC 能量垄断下，log 域 loss 里 DC 残差与高频残差梯度等强，
但 DC 通道只有 3/64 个参数位却携带 99.4% 能量——**参数位与能量严重失配**，
模型把容量浪费在 0.2% 能量的高频通道上，DC 精度上不去，整帧对比度就糊。

### 11.5 修正上一轮的错误结论

上一轮结论"质量下降主因是 min-max 出图口径"**部分错误**。正确表述：
- min-max 确实让画面更灰（std 4.8 vs 33.9），这是**显示层**问题，已修口径
- 但**根本原因是模型 DC 通道精度不足**，无论用哪种口径都存在（clamp 口径下
  方案 G 的对比度 32.1 vs target 36.2、振幅→target 仍能涨 6.44 dB）

### 11.6 下一步（已确认方向）

1. **DC 通道需要与 99.4% 能量匹配的容量**——不是加参数位，而是让 DC 通道的
   振幅预测走更短路径（当前 DC 与高频共用同一条 FFN 残差路径）
2. **块间平滑约束**：编码层相邻块的 DC 系数应平滑，模型无此先验
3. loss 回退到方案 D 的 AMP_P=0.5 log1p 口径，保留架构修复
4. 出图统一用固定 clamp / 分位裁剪，禁止 min-max 做质量评估

### 12.1 问题

### 12.2 第十二死穴：错误假设的三轮修正

### 12.3 第十三死穴：架构与 loss 的量纲错位（真正的架构 bug）

修完 loss 后跑 500 步，发现 **μ 报 −1.21 但模型实际层级是 +0.34，差 1.55**——
这违反「m 收敛到 μ」的设计。追查确认：

```
block.py    : m_new = m + γ_lvl·(μ − m)，  m = mean_N(log a)   ← μ 的稳态是 log 域
overfit.py  : loss_amp = (log1p(a) − log1p(a_tar))²            ← loss 是 log1p 域
```

**两套量纲从第一步就不同**，μ 永远差一个变换，只能靠震荡硬凑
（实测 μ 在 4~16 反复横跳、ch0 冲到 8.99、pix_mean 掉到 19/95.3 全黑）。

**修法**：架构整体搬到 log1p 域，与 loss 严格同量纲。

```python
L     = torch.log1p(a.clamp(min=0.0))          # a→0 时 L→0，有界
m     = L.mean(dim=1, keepdim=True)
m_new = m + γ_lvl·(μ − m)
L_new = m_new + delta_new
a_new = torch.expm1(L_new.clamp(min=0.0, max=6.0))   # 上限 402
```

**μ 初值必须同步改**：`log(0.05)=−3.0` → `log1p(0.05)=0.0488`
（`PMNNCore.a_mu` 与 `PhysicsBlock` 的 `a_mu=None` 两处都要改，差 3.05 单位）

**验证**（`scripts/diag_log1p_fix.py`，5 项全过）：

```
[1] |模型层级 − μ| mean=0.000305  max=0.000331   ← 修复前差 1.55   ✓
[2] μ 初值 = 0.0488 = log1p(0.05)                            ✓
[3] target log1p 跨度 = 2.1685（有界可学）✓
[4] a_new 上限 expm1(6)=402.4，target ch0 max=24，余量 16.8×  ✓
[5] a.min() = 0.0274 ≥ 0（expm1 保证非负）✓
```

### 12.4 μ 学习率：80 → 5

log1p 域跨度只有 2.17（log 域 6.6），×80 相当于过冲 20 倍。
×5 时爬完 2.17 需约 1450 步，在 3000 步预算内从容收敛。

> **教训**：改 loss 的变换时，必须同步检查架构递推的变换、所有相关超参的量纲。
> 判据 `|mean_N(log1p(a)) − a_mu| < 0.01` 是量纲一致性的自动化检查。
