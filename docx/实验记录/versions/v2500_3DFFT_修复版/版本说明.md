## 4. 架构核心差异（block.py，与 v3000 方案 H 的分水岭）

| 维度 | v2500 方案 D（本版本） | v3000 方案 H |
|---|---|---|
| γ | **单 γ 可训练** `a_gamma=nn.Parameter(0.3)`，每 block 独立 | 双 γ 冻结 `a_gamma_lvl=0.5` / `a_gamma_shape=0.1` |
| μ | **每 block 独立 per-channel** `a_mu=full((64,), log(0.2))` | **block 间共享**，顶层 `PMNNCore.a_mu`，log1p 域初值 0.0488 |
| 振幅递推域 | **log 域** `log a_new = log a + res − γ·(log a − μ)`，`a_new=exp(...)` clamp(-20,5) | **log1p 域** `a_new=expm1(clamp(...))`，与 loss 同量纲 |
| 层级/形状 | 未分离（共享单 γ，第九死穴的病根，但视觉已最优） | 正交分离（零均值 res + 双 γ） |

**为什么方案 D 是"最优基线"但仍被追查**：单 γ 把「层级收敛」和「形状衰减」绑死，
是后续「糊/方块」的架构病根（第九~十一死穴），但**它的视觉还原度是目前已知最高的**，
所以先存档它作为锚点，再在其上派生修复版。

## 5. loss 口径（精确公式，复现必须一致）

```python
# 振幅（方案 D，AMP_P=0.5）
la  = torch.log1p(a.clamp(min=1e-8))
lt  = torch.log1p(a_tar.clamp(min=1e-8))
w   = (a_tar / a_tar.max().clamp(min=1e-8)).pow(0.5)
w   = w / w.mean().clamp(min=1e-8)          # ★ 必须归一化到 mean=1（否则 loss 缩小 30×）
loss_amp = (w * (la - lt).pow(2)).mean()

# 相位（功率加权）
w_ph = (a_tar ** 2).clamp(min=1e-8)
loss_ph = (w_ph * pe.pow(2)).sum() / w_ph.sum()   # pe = remainder(th-th_tar+π,2π)-π

loss = loss_amp + loss_ph
```

## 9. 已知缺陷（留档，供派生修复版参考）

1. **单 γ 绑死**：层级/形状共享一个 γ，是后续第九死穴的架构病根。
2. **全局尺度放大 2.5~2.8×**：AMP_P=0.5 权重诱导"抬绝对值"而非"调比例"，frame-diff 过冲（10.26 vs target 5.56）。
3. **min-max 出图被离群 FFT 系数绑架**：本版本主出图 normalize=True 是可视化口径，质量评估应用 clamp 口径。
4. **频段诊断按 0/16/32/48 四等分**：未按真实 rfft2 网格（h_fft=3×w_fft=25）切，频段比读数失真（v3000 已修）。
