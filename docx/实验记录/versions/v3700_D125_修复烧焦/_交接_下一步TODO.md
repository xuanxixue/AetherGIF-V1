## P1. 诊断与分析

### 1.1 训练阶段诊断指标

| 指标 | 期望趋势 | 数值范围（参考） | 诊断意义 |
|------|----------|------------------|----------|
| loss | 下降 | 从 ~0.9 → 0.4~0.5 | 损失收敛，模型在学习 |
| cos | 上升 | 从 ~0.1 → 0.6+ | 条件响应增强，生成内容匹配 |
| loss 稳定性 | 平稳下降 | 无剧烈波动 | 训练稳定，未崩溃 |

**成功信号**:
- loss 明显下降（>20% 降幅）
- cos 相似度显著上升（>0.5）
- 无 NaN 或梯度爆炸

**失败信号**:
- loss 不变或上升
- cos 停留在 0.1 以下
- 输出纯噪点或全灰图像

### 1.2 生成 GIF 质量检查

运行后检查 `outputs_real/cond_gen_v4.gif`:

1. **视觉观察**:
   - 是否有结构化内容（非纯噪点）
   - 是否有明显动画效果（对比度变化）
   - 是否重复（可能变成图像）

2. **技术指标**（与 v3700 基线对比）:
   - 运行 `eval_gif.py` 或 `inspect_gif.py` 获取：
     - 对比度 std
     - 边界跳变
     - 网格比
     - Sobel 锐度

## 常见问题速查

**Q1: 日志不输出怎么办？**
- 检查是否设置 `-u` 缓冲参数
- 尝试直接控制台运行

**Q2: 显存不足怎么办？**
- 当前 batch=1，已是最低配置
- 检查是否还有其他占用显存的进程

**Q3: 训练 100 步后 loss 不变？**
- 可能学习率太低，尝试 `5e-4`
- 尝试调整冷却参数

**Q4: 生成 GIF 全是噪点？**
- 可能是训练步数不足，尝试 500+ 步
- 检查 CLIP 特征缓存是否正确

**Q5: 编译错误？**
- 运行 `py_compile scripts/test_cond_gen_v4.py` 诊断
- 检查 Python 语法和 import
