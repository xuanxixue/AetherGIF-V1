## P0. 修复「条件未分化」—— 唯一阻塞点

**现状**：最新代码（`cond_field.py`）已做两处重构但未验证：
1. chan_amp 从全局共享 → 条件调制（`to_chan` 层：`amp[b,k,c]=chan_amp[k,c]·(1+tanh(delta)·0.5)`）。
2. supervise() 去范数归一 → 只做逐位置中心化（保留幅度尺度）。

**要做的**：
1. **先 `py_compile` 确认能编译**（有没有语法/未定义变量残留）。
2. 跑一次 100~150 步短训（`--limit 200 --max-steps 150 --no-early-stop`），用**三个数字**判断条件是否分化：
   - 混合权重跨基 std：应明显 > 均匀基线 0.03634（之前卡在 0.00121）。
   - 不同 group 输出场两两平均差：应明显 > 1e-5 量级（之前卡在 5.7e-06）。
   - chan_amp 的 std：应显著偏离初值 0.02（之前卡在 0.02015）。
3. 如果还是不动，按下面的排查顺序依次试：

### 排查顺序（从最可能到最不可能）
1. **`to_chan` 零初始化是否反而压死了梯度**。当前 `to_chan.weight/bias` 都是 `zeros_` 初始化，
   `tanh(delta)·0.5` 起步是纯 0，`amp = chan_amp·(1+0)` = chan_amp。这是"不破坏起点"的设计，
   但如果 Adam 对零初始化的大矩阵起不动（2nd moment 累积慢），可以改成 `randn*0.02` 小初始化试。
   注意改这个要先回看 `cond_field.py` 102 行附近"不能全零"的原注释。
2. **supervise 的中心化位置**。当前 `lp = la_p - la_p.mean(dim=1, keepdim=True)` 是按 dim=1（position 维）
   中心化。确认它没有误把"通道幅度信息"也一起消掉（channel 是 dim=2，理论不受影响，但要实测）。
3. **gen_weight 太小**。默认 2.0，但 >4.0 会 NaN。可在 2.0~3.5 之间梯度搜一下，凡是 NaN 就回退。
4. **lr 对 cond_field 单独分组**。这一项是项目一贯的"分组 lr"手法（禁止注入先验，加速靠分组 lr）：
   给 cond_field 开一个更高的 lr（如 3~5× 全局），因为它是新加的、起点随机，需要更大步长追上已训好的物理核。

### 验收信号（P0 完成的判据）
拿到一份短训日志，里面 **w_std 与场差都显著超过基线**，即可判定条件分化成功，进入 P1。

## P3. 验收

### 验收线（用户原话）
- **生成质量不低于 v3700_D125_修复烧焦**。
- 目标不是"泛化出没见过的"，而是"在见过的数据里**组合出没见过的**"。

### 验收动作
1. **组合生成验收**：用 `gen_from_trainset.py` 或 `infer.py`，拿训练集里出现过的 group 文本/图像条件生成 GIF，
   确认画面是对的（不是噪点、不是千篇一律）。
2. **画质对比**：`eval_generalize.py` 已写好口径（对比度 std / 边界-内部跳变 / 网格比 / Sobel / PSNR clamp）。
   基准参照（图像空间，PATCH=4）：
   ```
   原始素材        边界4.99 内部4.94 网格比1.010 std42.8 Sobel4.20
   codec天花板     边界6.81 内部5.59 网格比1.218 std35.9 Sobel4.89  ← 架构上限
   （v3700 就卡在这附近，v4200 不应更好，但不能明显更差）
   ```
3. **对照旧版**：确认 v4200 输出与 v3700 不差，即过验收。
