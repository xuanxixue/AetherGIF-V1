# AetherGIF v3600 — Technical Report

**A physics-based generative architecture for GIF / short-video synthesis**
*(Plan D configuration, full-spectrum D=125 codec)*

> **One-line positioning.** AetherGIF is an **experimental model** built to answer a
> single research question: *can a video/gif be generated by an architecture made of
> coupled-oscillator physics alone — Kuramoto synchronization, mean-field order
> parameters, resonance-drive response, and thermodynamic annealing — instead of
> self-attention and Transformer blocks?* v3600 is the Plan-D configuration of that
> experiment, trained end-to-end on a single 3-second GIF clip, and it does reproduce
> the clip: **power-weighted phase cosine 0.9991, spectral-profile cosine 0.9967,
> 19.84 dB pixel PSNR against the codec ceiling after 2,500 steps** (see §8).
>
> **Identity fingerprint.** Total trainable parameters = **2,022,232** (slim checkpoint,
> frozen Qwen encoder excluded). This number is the rollback / reproducibility anchor
> for this snapshot.
>
> **What this is not.** It is not a production text-to-GIF product and it is not a
> general-purpose video model. It is a **single-sample overfit experiment** that
> validates the physical generation pathway end-to-end (noise → oscillators → pixels).
> Generalization across clips is an open research item (see §11).

## 4. The codec: GIF ↔ oscillator field (deterministic, zero-parameter)

The codec is a **fixed linear transform with no learnable parameters**. Its job is to
turn a GIF into a complex-valued oscillator field, and back.

**Configuration.** `IMG=128` (frame size) · `PATCH=4` (spatial block size) ·
`GRID=32 = 128/4` (spatial blocks per frame) · `WIN=5` (frames per temporal block) ·
`TS=6` (data time steps) · 30 frames total at 10 fps = 3 seconds.

**Encode.**

1. Load the GIF *(seek each frame **before** `convert("RGB")` — converting first
   collapses multi-frame animations to a single frame)*, resize to 128×128, linearly
   resample in time to exactly `TS × WIN = 30` frames.
2. Map pixels to `[-1, 1]` via `x/127.5 − 1`.
3. Tile into spatiotemporal blocks `[TS, WIN, GRID, PATCH, GRID, PATCH, 3]` and
   transpose to `N × WIN × S` where `N = TS·GRID² = 6,144` blocks and
   `S = PATCH²·3 = 48` real values per frame-block.
4. `rfft2` over the last two axes → **5 × 25 = 125 complex coefficients per block**,
   scaled by the fixed constant `NORM = 10.0`.
5. Keep all 125 coefficients (this is the v3600 change), flatten, and split into
   real/imag parts → **oscillator field `[N, 2D] = [6144, 250]`**, i.e. 6,144
   oscillators × 125 complex channels.

**Decode.** Reverse the above: reassemble `z`, multiply back by `10.0`, `irfft2`,
permute back to `[30, 128, 128, 3]`, clamp to `[-1.2, 1.2]` (the "honest" fixed-clamp
口径) or per-clip min–max normalize (the visualization 口径), then to `uint8`.

**Why `NORM = 10`.** rfft2 coefficients are extremely heavy-tailed (measured mean
`|z| ≈ 2.95` across Noto GIFs, median ≈ 0.0015, p99 ≈ 5.4). Dividing by the raw
pixel count would push the target amplitude to ~0.008, nearly two orders of magnitude
below the model's natural output scale, forcing the amplitude pathway to learn a
90× compression through a 12-layer chain. `NORM=10` aligns target and model scales;
encode and decode share the constant, so exact invertibility is preserved.

**Round-trip fidelity (measured, `diag_grid_source.py`).** With all 125 coefficients
retained, `rfft2 → irfft2` over the raw blocks reproduces the input with
max abs error ≈ **6e-7** — the FFT itself is *noiseless*. Any residual codec error is
therefore caused by (a) spectrum truncation and (b) `uint8` quantization, never by the
transform. This is the fact that makes the v3600 ablation interpretable.

## 5. Model architecture

```
GIF ──(codec, frozen)──▶ oscillator field (a₀, θ₀) ──▶ PMNN core ──▶ (a, θ) ──(inverse codec)──▶ GIF
                              ▲                         │                                    │
                              │                         └── 12 × PhysicsBlock (see §5.1–5.5)   │
        text (optional) ──Qwen2.5-0.5B (frozen)──▶ 4 × Linear heads ──▶ ω bias / κ / T / drift target
```

**Core constraint.** Outside the frozen text encoder there is **no self-attention, no
Transformer block, and no conventional positionwise FFN**. The only dense projections
in the model are `W₁/W₂` inside the standing-wave layer and four text-conditioning
heads; all structure and nonlinearity come from physics — sinusoidal phase coupling,
Lorentzian resonance denominators, standing-wave products, and an Ornstein–Uhlenbeck
amplitude restoring force.

**State.** Each of the N = 6,144 oscillators carries, per channel d ∈ {1..125}, an
amplitude `a` and a phase `θ`. The model integrates this 2D field from noise to the
target field through `R = 12` physics blocks. Depth *is* physical time in this
architecture: block index `i` maps to `t = i/(R−1) ∈ [0,1]` (§5.5).

### 5.1 DriftField — the only target pathway

The drift field is the **sole channel through which target information enters phase
evolution** (initial `a₀/θ₀` are noise, `ω` is deterministic — §5.6). It computes an
attractor field in *phase space*:

```
g_i = Σ_j softmax_j( −‖ẑ_i − ẑ_j^tar‖² / τ ) · sin(θ_j^tar − θ_i)
```

Two design decisions were forced by failure analysis and are worth documenting:

- **L2-normalized distance.** Model amplitudes and target amplitudes can differ by
  ~90× early in training. Without normalization the softmax logits are dominated by
  `‖z_i‖²`, the attraction degenerates to a pull toward the origin, and all target
  phase information is lost. After normalization, `ẑ·ẑ = mean_d cos(θ_i−θ_j)` — the
  distance *becomes* the phase cosine distance, independent of amplitude scale.
- **Force = `sin(θ_j^tar − θ_i)`.** Periodic, bounded in [−1, 1], and exactly the
  gradient direction on the phase manifold; it vanishes when `θ_i` catches up with
  `θ_j^tar`. A raw complex difference `(y_j − x_i)` instead contaminates the phase
  update with amplitude mismatch and the field learns to "suppress amplitude" rather
  than "align phase".

Multi-scale τ (two octaves), plus a direct per-oscillator component
`sin(θ^tar − θ)` (weight `direct_weight`, training only), plus learnable prototypes
that act as attraction centers in generative mode. At inference (`targets=None`) the
field relaxes toward the prototypes.

**Memory engineering.** Training-time attraction is `N × N` (6,144² ≈ 37.8M pairs).
Full materialization plus backward does not fit 4 GB. The implementation uses a
two-pass chunked logsumexp (pass 1 computes row-wise `logZ_i`, pass 2 accumulates
normalized weighted sums) wrapped in gradient checkpointing. This is *mathematically
identical* to full materialization — standard logsumexp block merging — while peak
memory drops from `O(N·M)` to `O(N·chunk)`. All distances are computed in fp32:
`‖z‖²` sums reach ~10⁵ and blow past fp16's 65,504 limit.

### 5.2 KuramotoSync — phase synchronization (the attention replacement)

```
dθ_i/dt = ω_i + Σ_j W_ij · sin(θ_j − θ_i) + κ(t)·g_i + η(t)
```

Four coupling pathways, as specified by the AetherMind design:

1. **Mean-field order-parameter coupling** (rank-1, zero parameters):
   `Σ_j sin(θ_j−θ_i) → r·sin(ψ−θ_i)` with amplitude-weighted `r, ψ`. The normalizer
   must be `Σw_i`, not `N`; using `N` inflates `r` beyond its theoretical [0, 1] range.
2. **Spacetime Toeplitz coupling** (zero-parameter structural prior):
   `W_ij = exp(−λ_t|t_i−t_j| − λ_s‖p_i−p_j‖²)`. Temporal decay gives light-cone
   causality; spatial Gaussian decay gives locality. Note the spatial scale correction:
   normalized `[0,1]` coordinates must be converted back to grid units (×`(grid−1)²`),
   otherwise adjacent-grid distance is ~1/31, the kernel degenerates to all-ones, row
   sums reach ~1000, and phases spin dozens of radians per block.
3. **Drift guidance** `κ(t)·g_i` from §5.1.
4. **Langevin noise** `η ~ N(0, 2T·Δt)` (training only) — the fluctuation–dissipation
   link to the annealing schedule; the `Δt` factor is required for correct scaling.

**Numerics.** Euler integration, `dt = 0.1`. The incremental field is soft-saturated
by `Ω_max·tanh(dθ/Ω_max)` with `Ω_max = 8` — linear near the origin (weak signals
unaffected), bounded and differentiable everywhere; this prevents large-magnitude
positions from ricocheting between ±π.

**The evolution chain is never folded.** `θ` accumulates continuously across all 12
blocks; wrapping to `[−π, π]` happens only in the loss. Mid-chain wrapping has zero
gradient at the boundary and was a repeated cause of broken 12-layer gradient chains.
All downstream consumers (`sin(θ_j−θ_i)`, `z = a·e^{iθ}`, the standing-wave input, the
decoder) use trigonometric functions of θ and are naturally periodic.

### 5.3 StandingWaveFFN — resonance/standing-wave layer (the FFN replacement)

```
h = W₂( GELU( W₁·z ) ⊙ A(ω_d, ω_n) ⊙ SW(p) )
out = h  →  split into (log-amplitude residual, phase residual)
```

- **(a) Lorentzian resonance gain** `A(ω_d, ω_n) = 1/√((ω_d²−ω_n²)² + (2γ ω_d)²)`
  with `γ = 0.3`: when the drive frequency `ω_d(t)` sweeps past a channel's
  learnable natural frequency `ω_n`, that channel is amplified. This is frequency
  selectivity, i.e. the physical origin of the "channel mixing" a normal FFN performs.
- **(b) 3D standing-wave modulation** — the physical positional encoding:
  `SW_m(t,x,y) = cos(2π m_t t/T_ref)·cos(2π m_x x/X_ref)·cos(2π m_y y/Y_ref)`,
  with a learnable projection into the hidden dimension. Reference lengths are fixed
  and decoupled from runtime sequence length, so behavior extrapolates consistently
  across durations.
- **Resonance is complex-valued physics:** a driven oscillator's transfer function is
  `|H(ω)|·e^{iφ(ω)}` — it changes both amplitude and phase. Accordingly the layer
  outputs *two* residual heads (log-amplitude and phase), not one. Without the phase
  head, phase evolution has only two weak learnable degrees of freedom (ω bias, κ
  scale) and the weighted phase cosine oscillates without converging.
- **Zero-initialized output projection** `W₂`: the model starts as an identity map and
  the physics (Kuramoto + initial conditions) alone determine the first iterations;
  the layer learns corrections from there.

### 5.4 Amplitude update — log-domain OU restoring force (Plan D form)

```
res      = 2·tanh(log_res / 2)                     bounded per-layer residual
log a_new = log a + res − γ·(log a − μ)            γ learnable scalar, μ per-channel
log a_new = clamp(log a_new, −20, 5)
a_new     = exp(log a_new)
```

FFT amplitudes span orders of magnitude (per-channel means differ by up to 727×, e.g.
0.0247 mid-frequency vs. 7.84 DC; std/mean ≈ 5.75). Log-domain multiplicative updates
make gradients uniform on the log scale. Under pure accumulation the amplitude blows up
across 12 blocks (measured at 100× target); the Ornstein–Uhlenbeck term
`−γ(log a − μ)` — Brownian motion with a restoring force, whose Fokker–Planck
stationary distribution is bounded — is the classical stabilization mechanism.

**Plan D specifics (this snapshot).** A *single* trainable γ per block (init 0.3) and
an *independent per-channel μ per block*. The known weakness of this form is that one
γ simultaneously controls (i) level convergence toward μ and (ii) shape decay — the
"ninth pitfall" documented in later versions: when γ self-trains to ~0.04, 61% of the
initial level survives 12 blocks and μ cannot dominate it. v3600 keeps Plan D as-is
because Plan D remains the best-performing baseline; the ablation is documented so
future work can separate the two roles (later versions split γ into γ_level / γ_shape).

**Dimensional consistency warning (documented, not fixed in this snapshot).** The
architecture recurses in the `log` domain while the loss aggregates in the `log1p`
domain (§7). The two differ from the first step (measured gap ≈ 3.05 units on μ's
steady-state target), which is why μ oscillates instead of converging. Later versions
unify both on `log1p`; v3600 reports the Plan-D result as-is for baseline fidelity.

### 5.5 TimeField — depth as physical time

```
t = block_idx / (R − 1) ∈ [0, 1]
κ(t)   = κ_max · σ((t − t_c)/τ_c)          coupling-strength curriculum: chaos → lock-in
T(t)   = T_max·(1−t)^p + T_min             temperature annealing: hot explore → cold lock
ω_d(t) = ω_lo·(ω_hi/ω_lo)^t                drive-frequency geometric sweep: low → high
```

`ω_d`'s sweep endpoints are derived from a **learnable natural-frequency spectrum**, so
the curriculum itself is trainable; endpoints are clamped to keep `lo < hi` and the
sweep direction from flipping.

### 5.6 Initialization and determinism

- `a₀ = exp(randn·0.8 − 2.5)` — log-domain sampling matches the heavy-tailed FFT
  amplitude scale; `θ₀ ~ U(−π, π)`.
- **`ω` must be deterministic.** A deterministic quasi-random field over
  (spatial coordinate, temporal coordinate, channel index) gives spatially
  heterogeneous natural frequencies that are *identical every forward pass*. Resampling
  `ω` each forward pass replaces the dynamical system at every step — nothing can be
  learned.
- Text conditioning (optional): frozen Qwen2.5-0.5B → four `Linear` heads producing an
  ω bias, a drift-target bias, and κ/T scale factors. They set **boundary conditions**,
  they never alter the physics operators. All reported v3600 runs use `use_qwen=False`
  (a single learnable condition vector), isolating the physics core from the 500 MB
  encoder.

## 6. What v3600 changes: full-spectrum codec (D = 64 → 125)

With `PATCH=4, WIN=5` the rfft2 grid is exactly **5 × 25 = 125** coefficients per block.
The v2500 codec kept only the first 64 flattened coefficients. Because flattening is
row-major over `(h, w)`, taking "the first 64" is an **asymmetric hard truncation**: it
keeps rows h=0 and h=1 entirely, only w=0…12 of row h=2, and drops rows h=3 and h=4
completely. That discarded band carries ~10% of the clip's energy — but the harm is
asymmetric, not merely quantitative.

The artifact this produces is visible as an "LED grid": patch-boundary jumps that
should not exist, measurable as the ratio of column-differences *at* patch boundaries
to those *inside* patches. Diagnostic findings (all reproducible with
`scripts/verify_dmodel_ceiling.py` and `scripts/diag_grid_source.py`):

| Codec configuration | Round-trip PSNR | Grid ratio (source ≈ 1.111) |
|---|---|---|
| D = 64 (truncated, v2500) | 28.63 dB | 1.373 |
| **D = 125 (full, v3600)** | **49.82 dB** | **1.172** |
| full spectrum, pre-quantization | ~147 dB (error ≈ 6e-7) | 1.062 (≈ source value) |

Two conclusions drive the v3600 design:

1. **The FFT itself is noiseless.** With all 125 coefficients, round-trip error is
   ~6e-7 and the grid ratio equals the source's own value — the grid artifact
   *vanishes*. It was never caused by blockwise FFT; it was caused by truncation.
2. **Asymmetry is worse than quantity.** A genuine low-pass corner (h<3, w<13 — only
   39 coefficients, 88.4% energy retained, nearly the same energy as D=64's 89.8%)
   produces a *worse* grid ratio (1.276) than D=64's 1.192-style truncation. Energy
   accounting alone cannot predict the artifact; the *shape* of the truncation is what
   breaks patch-boundary continuity. This also explains why fine-tuning the model
   against the artifact (the earlier v3500 line of work) made no lasting progress —
   the defect was in the codec, not the physics.

v3600 therefore keeps **all 125** coefficients: `d_model` grows 64 → 125, the
parameter count grows 1,135,658 → 2,022,232, and the codec ceiling rises by ~21 dB.

## 7. Training protocol (Plan D)

Objective (matched to the codec's heavy-tailed statistics):

```
pe      = wrap_to_pi(θ_model − θ_target)
loss_amp = weighted_mean( (log1p(a) − log1p(a_tar))²,  w = (a_tar / a_tar.max)^0.5 )
loss_ph  = Σ (a_tar² · pe²) / Σ a_tar²
loss     = loss_amp + loss_ph
```

- **log1p amplitude loss**: bounded gradient at `a → 0`; without it the 20/393,216
  spike coefficients receive ~0.67% of their linear-domain gradient and are never fit.
- **`(a_tar/a_max)^0.5` weight softening** prevents the DC channel (which alone can
  carry >99% of the power) from monopolizing supervision. An earlier `a_tar²`-power
  weighting gave DC a 99.9% share and starved every other channel.
- **`a_tar²`-weighted phase loss** is the mirror of that fact: 69.4% of FFT
  coefficients have amplitude < 0.01, and their target phases are pure `atan2`
  numerical noise — weighting by power discards them.

Schedule (identical to the v2500 baseline): single AdamW optimizer, flat `lr = 3e-4`,
no warmup, no parameter groups; 2,500 steps; **fixed initial seed** (`torch.manual_seed(1234)`)
so the model memorizes one trajectory — the goal of this experiment is to validate the
*pathway's* capacity, not cross-sample generalization. Single training clip:
`3D87B14FBB731ED3A948AC6DD9EA6EBC.gif` (anime avatar; `a_tar` mean 0.35459,
std 1.19339, std/mean 3.366).

The trainer reports, every 25 steps, the global phase cosine, the power-weighted
cosine (`wcos`), the cosine restricted to high-energy coefficients (`cos_eff`, a_tar>1),
a five-band spectral readout split along the **true rfft2 w-axis**
(`W_FFT = 25`; channel `c ↔ (h = c//25, w = c%25)` — a uniform 0/16/32/48 split would
mix DC into the high-frequency bands and make the readout meaningless), and the
spectral profile cosine (per-channel log1p amplitude profile vs. target — 0 means the
spectrum has been flattened).

**Reading the table.** The unweighted mean phase cosine dips slightly during training
(0.9939 → 0.9885) *because* the model is raising the amplitudes of weak coefficients;
their (mostly noise) phases then enter the average. The metrics that track perceptual
fidelity — the power-weighted cosine and the spectral profile — both continue climbing
to 0.9991 and 0.9967. The model's per-channel amplitude span grows from 1× (flat) to
87× of the target's 238×, and the frequency-band readout closes to within a few
percent on every band (e.g. DC 1.02, low 1.13, mid-low 1.48, mid-high 2.18, high 1.71 —
all bands above 1.0 because the level term μ is still biased, the documented
log-vs-log1p mismatch of §5.4).

**Comparison with the v2500 Plan-D baseline.** The two runs use *different training
clips* (v2500: 8-ball; v3600: anime avatar), so pixel PSNR is not directly comparable;
the target-normalized metrics are:

| | v2500 (D=64, 8-ball) | **v3600 (D=125, avatar)** |
|---|---|---|
| Trainable parameters | 1,135,658 | **2,022,232** |
| wcos | 0.8707 | **0.9991** |
| profile_cos | 0.9899 | **0.9967** |

**Spatial-domain evaluation.** `scripts/eval_generalize.py` reports pixel std, per-band
boundary/internal jump ratios (the LED-grid measure), Sobel sharpness, p1–p99 dynamic
range, and frame differences, against the raw source and the codec ceiling. The lesson
embedded in that script generalizes to any acceptance protocol for this class of model:
*mean-value metrics lie* — log-amplitude ratios, mean cosines, and energy shares all
average away exactly the contrast losses that matter. Amplitude/contrast acceptance
must always be judged with spatial-domain statistics, and denoising/sharpness
acceptance must use the **raw source** as the floor, never a previously over-sharpened

## 10. Design principles (what the experiment established)

These are the load-bearing conclusions of the AetherGIF line of work, each of which
was discovered by a documented failure mode:

1. **Deterministic ω.** Resampling natural frequencies per forward pass changes the
   dynamical system every step; phase evolution cannot be learned. Spatial
   heterogeneity must come from a coordinate-indexed deterministic field.
2. **The drift field is the only target pathway.** With noise initial conditions and
   deterministic ω, target information reaches phase evolution *only* through the
   drift attractor — and it must be defined in phase space (`sin(θ^tar − θ)` with
   normalized distance), or amplitude mismatch turns the attraction into amplitude
   suppression.
3. **Amplitudes evolve multiplicatively in the log domain**, with an OU restoring
   force. LayerNorm-style additive updates lock the dynamic range and flatten the
   heavy-tailed spectrum.
4. **Phase chains are never wrapped.** Wrapping belongs in the loss only; boundary
   gradients are zero and silently break 12-layer credit assignment.
5. **Phases are power-weighted, amplitudes are log-domain softened.** Most FFT
   coefficients are numerical noise; unweighted phase supervision fits the noise.
6. **Depth is physical time.** Coupling curriculum + temperature annealing + drive
   frequency sweep give the block stack a coherent thermodynamic narrative
   (explore → lock-in), with the identity `∂U/∂θ_i = Σ_j W_ij sin(θ_j−θ_i)` —
   Kuramoto synchronization *is* XY-model energy minimization.
7. **The codec is part of the architecture.** A single `spec[:, :D]` truncation
   dominated every downstream visual metric; diagnose the codec before blaming the
   physics (or the loss).
8. **Mean metrics lie.** Accept on spatial-domain statistics, relative to the raw
   source; report power-weighted and profile cosines alongside naive means.

## 11. Known limitations

- **Single-sample overfit only.** Cross-clip generalization is unproven; the frozen
  seed is part of the protocol. Text-conditioned generation (`use_qwen=True`) is
  implemented and wired to four physics-conditioning heads but was not the subject of
  the reported runs.
- **Plan-D amplitude recursion** uses one γ for both level convergence and shape
  decay, and recurses in `log` while the loss aggregates in `log1p`. Both are
  documented weaknesses (§5.4), retained for baseline fidelity.
- **Fixed configuration**: 128×128, 3 s (30 frames @ 10 fps). Longer durations /
  variable-length generation are supported by the index builder but untrained.
- **Hardcoded dataset paths** in the diagnostic scripts (§3).
- **Cost.** The chunked two-pass drift field with checkpointing is what makes the
   model fit a 4 GB laptop GPU; it is not yet a fast architecture.
