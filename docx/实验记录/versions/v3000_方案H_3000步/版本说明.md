## 4. 架构核心差异（block.py，与 v2500 方案 D 的分水岭）

| 维度 | v2500 方案 D | v3000 方案 H（本版本） |
|---|---|---|
| γ | 单 γ 可训练，每 block 独立 | **双 γ 冻结**（层级 0.5 / 形状 0.1） |
| μ | 每 block 独立 per-channel | **block 间共享**，顶层单一 `a_mu` |
| 振幅递推域 | log 域 | **log1p 域**（与 loss 严格同量纲，第十三死穴修复） |
| 层级/形状 | 未分离 | **正交分离**（残差零均值 + 双 γ 递推） |

**核心递推**（block.py forward）：
```python
L = torch.log1p(a.clamp(min=0.0))          # a→0 时 L→0，有界
res = 2.0 * torch.tanh(log_res / 2.0)
res = res - res.mean(dim=1, keepdim=True)  # 残差零均值：只含形状
m = L.mean(dim=1, keepdim=True)
m_new = m + a_gamma_lvl * (a_mu.view(1,1,-1) - m)
delta_new = (1 - a_gamma_shape) * delta + res
L_new = m_new + delta_new
a_new = torch.expm1(L_new.clamp(min=0.0, max=6.0))   # ★ 第十四死穴：max=6 硬截断
```

## 5. loss 口径（精确公式）

```python
# 振幅（方案 H，log1p 无截断无权重）
la  = torch.log1p(a.clamp(min=0.0))
lt  = torch.log1p(a_tar)
loss_amp = (la - lt).pow(2).mean()         # 跨通道等权，无幅度权重

# 相位（功率加权，与 v2500 一致）
w_ph = (a_tar ** 2).clamp(min=1e-8)
loss_ph = (w_ph * pe.pow(2)).sum() / w_ph.sum()

loss = loss_amp + loss_ph
```

## 8. 已知缺陷（第十四死穴，留档）

`a_new = torch.expm1(L_new.clamp(min=0.0, max=6.0))` 的 **max=6 硬截断**：
L_new 被 clamp 到 6 时 a=expm1(6)=402，本意是防溢出；但 L 是 log1p 域且含乘积项，
实际有 **51.29% 的位置被钉在 a=0**（L_new 触到 min=0 的下界），破坏零均值残差不变量
`mean(delta_new)=0`，产生**块状色块伪影**。

**派生修复方向**：下界 soften（如 `clamp(min=-L.min()+eps)` 或改 softplus 平滑过渡），
并加「a=0 比例」断言（应 <1%），再重训。
