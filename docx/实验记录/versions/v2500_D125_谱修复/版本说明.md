## 二、本次实际改动（3 处真改动 + D 提升）

### 1. 编解码：2D rfft2 → 真 3D FFT（`src/codec/gif_codec.py`）
- 每块 `[win=5, patch=4, patch=4, 3通道]` → 对 `[时间,高,宽]` 三维做 `fftn`。
- 240 复系数按（时间,高,宽）中心化频率模升序，取前 D=125 最低频。
- `encode` 返回 `[N, 2D]` 实虚分离，`decode` 严格逆（同序补零 + `ifftn` 取实部）。
- **实测往返 PSNR = 34.77 dB**（原 2D 方案天花板约 26.7 dB）。

### 2. 漂移场：恢复 V = V⁺ − λV⁻（`src/physics/drift_field.py`）
- `_repel` 的复值排斥场取角向投影 `V⁻_θ = im·cosθ − re·sinθ`，真正进入相位通路。
- `g = V⁺_相位 − λ·V⁻_相位 + direct·sin(θ_tar−θ)`，双分量齐备。

### 3. D=64 → D=125（贯穿全链路）
- 125 个复振子（实虚 250 维）≈ 完整表示 240 实数输入的低频近似，接近无损。
- 改动文件：`aether_gif_model.py`、`block.py`（PhysicsBlock + PMNNCore）、`standing_wave_ffn.py`
  默认值 `d_model=125, ffn_hidden=512`；`overfit.py` 的 `D=125` 与模型构造、频段切分。
