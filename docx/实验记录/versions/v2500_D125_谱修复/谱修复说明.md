# v2500_D125_谱修复 —— 修「振幅谱压平」的对照版

> 对照对象：`v2500_D125_3DFFT`（你正在跑的未修复版，其训练日志显示
> `profile_cos=0.127`、`模型 1x`、`a_out 停在 0.2`——振幅频谱完全没学出来）。
> 本版只改「振幅谱包络」的梯度通路，其余（真 3D FFT、双分量漂移场、D=125）不动。

---

## 一、改动（2 处，都在振幅谱包络 μ 上）

### ① 共享谱包络 μ_c（修「每 block 独立 μ 只有末层收到有效梯度」）
- 原：12 个 PhysicsBlock 各建一个 `a_mu`（`nn.Parameter`），第 i 块对终态贡献
  `∝ γ·(1−γ)^(11−i)` 指数衰减，只有末层梯度有效。
- 改：`PMNNCore` 顶层新建 **一个** `self.a_mu`，经 `forward` 传给所有 block，
  梯度沿线累加（`Σγ(1−γ)^k ≈ 1`），谱包络成直通路径。

### ② 频谱先验初始化（修「均匀 log(0.2) 导致谱压平」）
- 原：`a_mu = torch.full((d_model,), log(0.2))`，125 通道全一样，模型停在全 a≈0.2。
- 改：按 3D 频率模做 1/f 衰减先验：
  ```
  a_mu[c] = log(0.05) − s · freq_mod[c]      s = 5 / freq_max
  ```
  `freq_mod[c]` 与 `codec.gif_codec._fftn_freq_order` 同一排序，低频 DC 大、高频小。
  log 域 span=5 ≈ ln(145)，直接对齐 target 的 145 倍跨通道差异。

## 三、已知残余（诚实标注，本次未改）

- **第九死穴（单 γ 绑死层级/形状）**：`a_gamma` 仍是单一可训练参数，Adam 可能
  走「把 γ 调小」的捷径。本次未拆 γ_lvl/γ_shape，先验证 ①② 能否把 profile_cos 拉起来。
- **第十三死穴（log 域递推 vs log1p 域 loss 量纲错位）**：仍在 log 域递推。若 ①② 后
  谱仍不够，再统一到 log1p 域。
