## 二、三级能力判据（对外口径以此为准）

| 级别 | 判据 | 当前 | 目标 |
|---|---|---|---|
| **L1 条件起效** | 同素材 4 条件一致（差 <0.05）**且** 跨素材 sat 比值进 0.8~1.25 | 一致性 ✅ / 分离度 ❌ | 2 素材 8/8 达标 |
| **L2 泛化生成** | 8~22 素材，每个素材 sat 比值进 0.8~1.25；相对判据正确率 >80% | 50%（随机） | 8 素材先达标 |
| **L3 组合泛化** | 新图片 + 旧动作，动作 wcos >0.7 且外观跟随新图 | 未测 | 至少 1 例成功 |

**铁律：「通路打通」≠「能力成立」。** 只要不同条件输出近似同一张图，能力就不成立。

## 三、阶段计划

### 阶段 0（本周）：把 L1 做完

**唯一目标**：2 素材 × 4 条件 = 8 个组合，sat 比值全部进 0.8~1.25。

**已试过的路与结论**：

| 尝试 | 结论 |
|---|---|
| rank 8→64（扩容量） | ❌ 无效，反而更坍（5.32→0.68） |
| `ANCHOR_W` 0.3→0.8 | ❌ 无效 |
| `THETA_PARAM=linear` | ✅ 有效（相位覆盖率 40%→52.5%） |
| `mu_head`（μ 条件调制） | ✅ 有效（分离度 0→1.34），但**饱和** |
| `mu_head` 接 `h` | ❌ 退步（LayerNorm 抹平信息） |

**下一步（按优先级）**：

1. **`mu_bias` 直接监督**（最高优先）
   ```
   loss_mu = MSE(mu_bias, μ_target − a_mu)
   ```
   训练时已知 `μ_target`（target 谱包络的 log1p 逐通道均值），
   这是**有标签的监督**，比对比损失可靠。预计一次到位。

2. 若①不足，给 `to_amp` 加同款直接监督（`a_hat` 当前变异系数仅 0.158，需 3 倍跨度）。

3. 若仍不足，检查 `a_gamma` 学到的值——若接近 0.5，需限制上限（`GAMMA_MAX`），
   否则 `(1−γ)^12` 太小，初值永远被洗掉。

**完成判据**：`docs/L1_验收报告.md` 里 8 个组合全 PASS。

---

### 阶段 1（1~2 个月）：L2 泛化生成

**目标**：8 素材全部达标，然后扩到 22。

**关键动作**：
1. 素材从 2 → 8（先少后多，避免 22 素材的管理复杂度）
2. `DISC_W` 逐步加到 8~15，监控 `cond_init` 输出余弦 <0.4
3. 每 100 步做一次 `sat 极差` 快照（不等到跑完）
4. 用**组合泛化实验**做交叉验证（见阶段 2）

**风险**：
- 22 素材时可能出现「部分素材学得好、部分学不动」，需要按素材难度分层采样
- 4GB 显存下 batch 只能是 1，训练慢（约 9~17 秒/步）

---

### 阶段 2（2~3 个月）：组合泛化验证（关键判定）

**这是最有价值的一个实验**，因为它同时验证「解耦表征」是否成立。

**设计**：
```
训练：22 个（角色, 动作）配对
测试：新角色图 A + 旧样本 B 的动作向量   ← 训练没见过的组合
判据：
  · 动作一致性：生成相位演化 vs 目标动作 wcos > 0.7
  · 外观一致性：生成首帧 vs 新角色图的结构相关 > 0.6
  · 两者同时满足才算成功
```

**若失败，修法（符合架构原则，不加注意力）**：

利用物理核已有的三路物理量做**分流注入**：

| 条件 | 绑定的物理量 | 现状 |
|---|---|---|
| 文本 | **ω（固有频率）** | 已有 `omega_bias_head` |
| 图片 | **μ（谱包络）** | 已有 `mu_head` ✅ |
| 视频 | **漂移场 targets（动作中心）** | 已有 `drift_target_head` |

**如果显式把三路各绑到一个物理量上，解耦就自然发生** ——
这比「拼接后让模型自己学」可靠，而且完全符合物理架构的逻辑。
**这是本架构相对 Transformer 的独有优势：靠物理量分工天然解耦。**

---

### 阶段 3（3~6 个月）：世界模型改造

**核心公式**：世界模型 = 当前物理核 + 动作条件 + 逐步 rollout + 长期稳定

#### 3.1 动作条件注入（最关键，4GB 卡就能做）

把动作当**控制输入**（不是文本描述）：

```
dθ/dt = ω + κ·Σsin(θ_j−θ_i) + B·u(t)
                            ↑ 控制矩阵，可学习
```

```python
self.B_ctrl = nn.Linear(action_dim, n_osc * d_model)  # 低秩分解
# theta_new = theta + κ*g(theta) + res + B @ u_action
```

**物理依据**：Kuramoto 振子本来就受外力驱动，动作就是外力。不是强行套用。

**验证判据**：同一初始态，两个不同动作 → 轨迹差异 > 阈值。

#### 3.2 自回归 rollout

- 当前是「一次前向出全片」，世界模型需要 `s_{t+1} = f(s_t, a_t)`
- 改造：把 12 层从「空间演化」改为「单步时间演化」（或 3 层 × 4 时间步）
- 外循环 rollout，状态**继承上一帧**
- 训练用 teacher forcing + BPTT 2~4 步（成本上升 3~5 倍，梯度检查点可撑）

#### 3.3 长期稳定性（物理方案，不靠 loss 硬压）

| 手段 | 物理依据 |
|---|---|
| 能量守恒正则 | 无外力时系统能量应守恒，惩罚 `|E_t − E_0|` |
| 阻尼项 | 真实系统有耗散，防能量爆 |
| 相位锚定 per-step | 防长时间漂移 |

**这三条都有物理依据，不是黑箱正则** —— 这是本架构比 Transformer 占优的地方：
**稳定性可解释，不是靠调参试出来的。**

#### 3.4 3D 表征（最后做）

位置数随分辨率**立方**增长，4GB 卡几乎不可能。
**建议先做「伪 3D」（2.5D 深度层）验证思路，再考虑扩展。**

## 四、可借鉴 vs 不可抄（世界模型）

| 借鉴（思想） | 不抄（方法） |
|---|---|
| latent state + transition | ❌ Transformer 注意力转移 |
| action-conditioned | ❌ Diffusion 去噪过程 |
| imagination rollout | ❌ VAE 重参数化 |
| predictor + decoder 分离 | ❌ 特定 loss 公式 |

**架构不同，方法不能照搬。借鉴「要做什么」，不借鉴「怎么用神经网络做」。**

## 五、资源需求与瓶颈

### 当前瓶颈（按严重度）

| 瓶颈 | 影响 | 缓解 |
|---|---|---|
| **4GB 显存** | batch=1，训练慢 9~17 秒/步 | 梯度检查点 + 8bit 优化器（已用） |
| **物理内存 15.7GB** | 内存不足时训练慢 5~7 倍（已实测 51 秒/步） | 训练前确认空闲 ≥1.5GB |
| **无动作数据集** | 世界模型无法启动 | 需自建（GIF 无法提供动作标签） |
| 单人开发 | 迭代速度受限 | — |

### 若要推进世界模型，最小资源需求

| 项 | 最小配置 | 用途 |
|---|---|---|
| GPU | 1× 24GB（4090/A10） | 能做 rollout 训练（4GB 做不了） |
| 数据 | 100~500 小时带动作标签视频 | 世界模型入场券 |
| 人力 | 1 人（能调试 + 能做实验） | 不是 3 个学科专家 |

## 七、对外表述规范（避免过度承诺）

### 可以说

- 「4GB 显存训练 109M 参数模型，峰值 3695/4096 MiB」（实测）
- 「单次生成 2~4 秒，一次前向出 30 帧」（实测）
- 「Codec 往返 PSNR 49.82 dB」（实测）
- 「物理重建 wcos 0.9991」（实测）

### 不可以说

- ❌ 「细节超还原」——PSNR 只有 19.84 dB，且频域表征体积是原始 4.17 倍
- ❌ 「比海螺/可灵便宜」——720P 未验证，位置数会涨 1406 倍
- ❌ 「具备泛化生成能力」——L1 都没过
- ❌ 「可以做世界模型」——动作条件、rollout、3D 都还没有

### 正确姿势

> 有数据的说数据，没数据的说「目标」，**绝不混着讲**。
