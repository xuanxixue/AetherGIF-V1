# AetherGIF 技术实现详解

> 纯技术文档。只描述**用什么技术、怎么实现**，含数学定义、张量形状、数值口径。
> 所有数值均来自代码实测，不含推测。

---

## 0. 符号约定

| 符号 | 含义 | 取值 |
|---|---|---|
| `T_s` | 时间采样步数 | 6 |
| `G` | 空间网格边长 | 32 |
| `P` | 块边长 | 4 |
| `W` | 每时间步包含的原始帧数 | 5 |
| `H=W_img` | 分辨率 | 128 |
| `S` | 块内展平维度 = `P·P·3` | 48 |
| `F_s` | 块内空间频点数 = `S/2+1` | 25 |
| `D` | 频域系数维度 = `T_s · F_s` | 125 |
| `N` | 振子总数 = `T_s · G²` | 6144 |
| `B` | 批大小（训练恒为 1） | 1 |

**振子状态**：每个振子持有复值 `z = a·e^{iθ}`，其中 `a ∈ R_{>0}` 为振幅、`θ ∈ R` 为相位。
张量形状 `a, θ ∈ R^{B×N×D}`。实虚分离存为 `[N, 2D]`（实部前 D、虚部后 D）。

## 1. 表征层：时空频域编码

### 1.1 前向编码（GIF → 振子场）

输入 GIF 先重采样为 `T_s·W = 30` 帧、`128×128`、`[-1,1]` 浮点：

```
x = frame/127.5 − 1.0                                        ∈ [-1,1]
```

不直接对整帧做 FFT，而是**先分块再做块内 2D-RFFT**，原因是整帧 FFT 会混合局部与全局频率、且 `128×128` 的频点利用率低。

分块 reshape（`xt = x.reshape(T_s, W, G, P, G, P, 3)`）：

```
blocks = xt.transpose(0,2,4,1,3,5,6).reshape(T_s·G·G, W, P·P·3)
       形状 [N, 5, 48]
```

对最后两维（`W` 与 `S`）做 `rfft2`：

```
spec = rfft2(blocks, dim=(−2,−1)) / NORM
     形状 [N, W, F_s] = [N, 5, 25] → reshape → [N, 125]
```

**`NORM = 10.0` 的量纲标定**：`rfft2` 系数是重尾分布（低频巨大、高频极小），实测 20 个样本的 `|z|.mean ≈ 2.95`。若按像素数 `S=240` 归一，target 会被压到 `≈0.008`，而模型 `softplus` 输出自然量级为 `0.3~0.7`——两者相差近 90 倍，振幅项要额外学一个 90 倍的压缩，梯度到 12 层后的路径过长。取 `NORM=10` 把 target 均值对齐到 `≈0.3`，与模型输出同量级。**编码/解码使用同一常数，互逆性严格保持**。

截断到 `D` 维（`D=125` 恰等于 `5×25`，全保留），实虚分离：

```
z = spec[:, :D]                                              [N, 125] 复
field = cat([z.real, z.imag], −1)                            [N, 250] 实
```

### 1.2 逆向解码（振子场 → 帧）

```
z = field[:, :D] + 1j·field[:, D:]                           [N, D]
z = z × 10.0                                                 （乘回 NORM）
z = z.reshape(N, W, F_s) → irfft2(dim=(−2,−1), s=(W, S)) → [N, 5, 48]
→ 逆 reshape → [T_s·W, H, H, 3]
```

**两种归一化口径（必须区分）**：

| 模式 | 变换 | 用途 |
|---|---|---|
| `normalize=False` | 固定 `clamp(±1.2)` | 编解码往返测试（与 encode 严格互逆） |
| `normalize=True` | per-clip min-max 拉到 `[-1,1]` | 模型生成可视化（模型输出幅度未收敛时，固定 clamp 会整体过曝成二值图） |

**窗函数约束**：块内频率变换必须保证 `(h=0,w=0)` 处增益为 `1.0`。Hann 窗在直流处增益为 0.5，会压掉 79.7% 的能量（DC 通道承载 97.2% 的信号能量），因此禁用 Hann。

### 1.3 频域—空间对应关系（颜色通道）

`S = P·P·3 = 48`，其中颜色维度是**最后一位**、周期为 3。沿 48 维做 RFFT 后，颜色差异落在 **`w = 48/3 = 16`** 频点。

因此**颜色在振子场中只由 `w=16` 的 5 个时间频段承载**，即通道索引 `{c | c mod 25 == 16} = {16, 41, 66, 91, 116}`。

实测验证（去掉/只留 `w=16` 后重建）：

| 样本 | 完整 sat | 去掉 w=16 | 只留 w=16 |
|---|---|---|---|
| 8-ball | 6.36 | **0.51** | **6.85** |
| senpai | 9.87 | **2.85** | **9.79** |

→ 其余 120 个通道对颜色几乎无贡献。**约束颜色必须直接作用于这 5 个通道，在空间域算饱和度是舍近求远。**

## 2. 物理演化层

### 2.1 状态与时间参数化

层数编号归一化为物理时间：

```
t_i = i / (n_blocks − 1) ∈ [0,1],   i = 0..11
```

`TimeField` 把 `t` 映射成三条协议曲线，模拟"从混沌到有序"的退火过程：

**① 耦合强度课程（混沌 → 锁相）**
```
κ(t) = κ_max · σ((t − t_c)/τ_c)
```
`κ_max=16.0, t_c=0.3, τ_c=0.15`。浅层 κ 小（耦合弱，允许自由探索），深层 κ 大（强同步）。

**② 温度退火（冷却）**
```
T(t) = T_max·(1−t)^p + T_min
```
`T_max=1.0, T_min=0.05, p=1.5`。

**③ 驱动频率几何扫描（低频 → 高频）**
```
ω_d(t) = ω_lo · (ω_hi/ω_lo)^t
```
端点 `ω_lo, ω_hi` 由可学习固有频率谱 `natural_freq` 的低/高分位均值给出，使**课程本身可训练**（梯度可回传），否则是死参数。

### 2.2 Kuramoto 相位同步

连续形式：

```
dθ_i/dt = ω_i + Σ_j W_ij·sin(θ_j − θ_i) + κ(t)·g_i + η(t)
```

离散实现的关键是**避免物化 `[N,N]` 耦合矩阵**。利用三角恒等式：

```
Σ_j W_ij·sin(θ_j−θ_i) = cosθ_i·(W·sinθ)_i − sinθ_i·(W·cosθ)_i
```

即把 `O(N²)` 的逐对计算转为两次线性变换。`W` 由 `SpacetimeToeplitzCoupling` 给出，是**时间-空间 Toeplitz 结构**：

- 空间耦合权重 `W_s`：由 `(Δx, Δy)` 距离的高斯核构建，`λ_s=3.0` 控制衰减
- 时间耦合：`Δt ∈ {0..2}`（`temporal_window=3`），`λ_t=0.5`；`Δt=0` 为帧内耦合（`sin(0)=0` 自然无自耦），`Δt>0` 为跨帧耦合，同时做前向与反向双向计算以保持时间可逆性

**平均场项**（`MeanFieldCoupling`）：用序参量 `r, ψ` 替代逐对求和

```
r·cosψ = Σ_i w_i·cosθ_i / Σ w_i,   r·sinψ = Σ_i w_i·sinθ_i / Σ w_i,   w_i = softplus(a_i)
r·sin(ψ−θ_i) = r·sinψ·cosθ_i − r·cosψ·sinθ_i
```

`r` 天然 `clamp(max=1.0)`，作为同步程度的可测指标参与诊断。

**相位不折叠**：演化链中相位保持连续累积，`remainder` 只在 loss 计算处做。实测相位在 `±π` 附近折叠会造成帧间断裂（frame-diff 从 14.7 降到 4.6）。

### 2.3 共振-驻波前馈（替代 FFN）

```
h = σ( W_2·(W_1·z + b_1) ⊙ A(ω_d, ω_n) ⊙ SW(p) + b_2 )
```

**非线性来源不是激活函数，而是两个物理机制：**

**(a) 洛伦兹共振增益（频率选择性）**
```
A(ω_d, ω_n) = 1 / sqrt((ω_d² − ω_n²)² + (2γ·ω_d)²)
```
`γ = 0.3`。当驱动频率 `ω_d(t)` 接近某通道固有频率 `ω_n` 时该通道被放大——这是**带通滤波**，实现"哪些频率的通道在当前时刻响应"的动态路由。

**(b) 3D 驻波调制（位置感知，物理版 RoPE）**
```
SW_{m}(t,x,y) = cos(2π·m_t·t/T_ref) · cos(2π·m_x·x/X_ref) · cos(2π·m_y·y/Y_ref)
```
`n_modes_t=4, n_modes_xy=4, T_ref=20.0, X_ref=Y_ref=32.0`。
**参考长度固定**（与运行时序列长度解耦），保证跨时长外推的一致性。前向波与后向波叠加形成驻波，振子的时空坐标充当空间坐标。

### 2.4 漂移场（吸引—排斥）

```
V = V⁺ − λ·V⁻

V⁺ = Σ_k softmax_τ(−‖z_i − z_k^tar‖²)·(z_k^tar − z_i)     吸引：向目标靠拢
V⁻ = Σ_j softmax_τ(−‖z_i − z_j‖²)·(z_j − z_i)              排斥：防坍缩
```
`λ = 0.5`，多温度 `τ` 求和实现多尺度。距离在**实+虚拼接的 2D 空间**定义。

**漂移场是唯一把 target 信息送入相位演化的通路。** 正磁场（纯耦合项）不含 target 信息，缺了漂移场相位就失去方向。

**显存工程（不改动任何公式）**：全 pairwise 距离矩阵是 `O(N·M)`，训练时 `M = N = 6144`，单个 `[1,6144,6144]` fp32 就 151MB，连续物化 + 反向必爆 4GB。采用**分块两遍 + 梯度检查点**：

```
Pass 1：分块求每行 i 的全局 logsumexp（softmax 归一化常数 logZ_i）
Pass 2：分块累加 Σ_j w_ij·y_j 与 Σ_j w_ij，  w_ij = exp(l_ij − logZ_i)
```

数学与全物化**严格等价**（标准 logsumexp 分块合并），峰值显存从 `O(N·M)` 降到 `O(N·chunk)`。

**必须 fp32**：`z = a·e^{iθ}` 是 2D 维、元素 `±a`（max≈8），`‖z‖²` 求和可达 `~10⁵`，超 fp16 上限 65504 直接溢出；且三数相减存在灾难性抵消。距离全程升 fp32。

### 2.5 PhysicsBlock 完整递推

单块内按序执行：

```
① 相位：θ_new = θ + [Σ_j W_ij·sin(θ_j−θ_i)] + V_drift + κ(t)·g(θ)   （不折叠）
② 振幅（log 域乘性）：log_a_new = log_a + res − γ·(log_a − μ)
                      a_new = exp(clamp(log_a_new, −20, 5))
③ 残差限幅：res = RES_LIMIT·tanh(log_res/RES_LIMIT),  RES_LIMIT=0.5
```

**振幅演化的量纲**：`μ` 是 `log1p` 域的逐通道谱包络（**不是** `log` 域）。用错量纲会让 `μ` 从第一步就偏离目标（实测差 3.05 个单位）。

**`γ` 的作用与代价**：`γ` 是可学习的 OU 回复率（初值 0.3）。它把通道层级 `m = mean_N(log a)` 拉向可学习先验 `μ`，提供 Fokker-Planck 稳态有界性（防止 12 层堆叠下振幅爆到 100×target）。代价是：

```
m_12 = μ + (m_0 − μ)·(1−γ)^12
γ=0.3 → 0.7^12 ≈ 0.014
γ=0.5 → 0.5^12 ≈ 2.4e-4
```

**即条件注入的初值 `m_0` 在 12 层后只剩 1.4%~0.02% 的贡献，终态层级 ≡ μ。**

**`μ` 的 per-channel 必要性**：FFT 振幅谱是重尾的，同一 GIF 每通道振幅均值跨 **727 倍**（低频通道 0.573、中高频 0.0247、DC 通道 7.84）。若 `μ` 为标量，会把中高频抬高约 8 倍、低频压低，整张谱被压平（表现为"有轨迹没细节"，帧内对比度只有 target 的 1/3）。

**`μ` 必须 block 间共享**：第 `i` 块对终态的贡献 `∝ γ·(1−γ)^(11−i)`，前面块指数衰减、梯度几乎为零。一个共享 `μ` 让 12 次递推都朝同一平衡点靠近，梯度沿线累加 `Σ γ(1−γ)^k ≈ 1`，谱包络成为直通路径。

### 2.6 热力学判据层（诊断，不参与梯度）

```
U(Z) = −Σ_ij W_ij·cos(θ_j − θ_i)           XY 能量（锁相 = 能量最小化）
S(Z) = −Σ_i p_i·log p_i,  p_i = softmax(a_i)   振幅分布熵
F = U − T·S                                 自由能
```

核心恒等式：

```
∂U/∂θ_i = Σ_j W_ij·sin(θ_j − θ_i)
```

**Kuramoto 的 sin 耦合就是 XY 能量的梯度**——同步层不是在"模拟物理现象"，而是在做能量最小化。这一同源性是架构自洽性的依据。

**`S` 的维度必须显式指定**：`U` 依赖时间维序参量，`S` 依赖通道维振幅分布。两者混用会导致判据失效（`S_chan` 与 `S_time` 严格分离）。

## 3. 条件注入

### 3.1 三路条件向量构造

单条样本的条件向量为 `6147` 维：

```
cv = [ text(2048) | first(2048) | gif(2048) | has_text(1) | has_first(1) | has_gif(1) ]
```

`text/first/gif` 来自冻结的 Qwen3-VL-Embedding-2B（在线编码或离线缓存 `.npy`）。`has` 三位是**模态存在标志**，训练时按组合采样（7 种组合：三路全给 / 文生 / 图生 / GIF本身 / 图文生 / 文+GIF / 图+GIF）。

### 3.2 CondInitPC：条件 → 逐通道初始态

```
h = LayerNorm( SiLU( Linear_{512←512}( SiLU( Linear_{512←6147}(cv) ) ) ) )     [B,512]

θ̂ = wrap( to_phase(h) )        to_phase: Linear_{512→rank} → Linear_{rank→N·D=768000}
â = softplus( to_amp(h) )       to_amp  : 同构

dθ = wrap(θ̂ − θ_0),  dln a = log(â) − log(a_0)
→ 初值取 θ_0+dθ ≡ θ̂ (mod 2π)、a_0·exp(dln a) = â，随机初相位/幅度抖动被精确抵消
```

**低秩分解是显存约束下的必然选择**：`Linear(hidden→N·D)` 单层就是 `512×768000 = 393M` 参数，4GB 显存直接 OOM。低秩 `rank` 是容量主旋钮：

| rank | 总参数 | cond_init |
|---|---|---|
| 8 | 23.04M | 17.24M |
| 32 | 59.93M | 54.13M |
| 64 | **109.12M** | 103.32M |

`rank` 通过环境变量 `COND_PC_RANK` 控制。

**相位参数化（关键）**：

| 模式 | 定义 | 导数 | 问题 |
|---|---|---|---|
| `arctan`（旧） | `θ̂ = arctan(pre)·2` | `2/(1+pre²)` | `\|pre\|>3` 时梯度趋 0，实测训 300 步后 `to_phase[1] \|w\|` 仅 **0.0131** |
| `linear`（新） | `θ̂ = wrap(pre)` | `1` | 不饱和，同样权重能产生更大相位跨度 |

由 `THETA_PARAM` 切换。实测 `linear` 模式下相位输出标准差从 0.658 rad 升到 0.865 rad。

### 3.3 μ 条件调制（mu_head）

在 §2.5 的振幅递推中，`μ` 不是常数，而是条件相关：

```
μ = μ_c + mu_bias
mu_bias = MU_SCALE · tanh( mu_head(cond) )
mu_head: Linear_{256←512} → SiLU → Linear_{125←256}
```

**设计依据**：终态层级 `m_12 → μ`。若 `μ` 全样本共享，则所有条件收敛到同一谱包络 → 所有输出同一饱和度的图像（实测 sat 锁死在 6.0~6.9，与素材和条件均无关）。**收敛到平衡点是物理性质（不应改），但每个条件应当拥有自己的平衡点。**

`mu_head` 末层**零初始化**（`zero_init`），起步时等价于原 `μ_c`，不破坏已训练的谱包络；训练中逐渐学会按条件偏移。`MU_SCALE` 控制幅度（`tanh` 使上限为 `±MU_SCALE`，对应振幅比 `e^{±MU_SCALE}`）。

**经验边界**：`MU_SCALE` 从 0.5 → 2.0 时，两样本 sat 分离度从 −0.30 升到 +1.27；继续升到 6.0 只到 +1.34（饱和）。原因是 `mu_head` 输入为原始 `cond_vec`（样本间余弦仅 0.19~0.33，差异不足），而不是容量或缩放问题。

### 3.4 FFT 场旁路

除低秩条件头外，另有逐位置的 FFT 场旁路：把目标场（训练时）或缓存场（推理时）经小网络映射为 `dθ, dlna`，直接叠加到初始态。

**逐位置而非全连接**：`hidden(512) → N·D(768K)` 单层要 1.46GB，4GB 显存 OOM。旁路参数量与 `N` 解耦（约 0.15M）。

实测优势明确：仅用 FFT 场逐位置解码，幅度相关可达 `+0.8541`；而 CLIP 条件通路经 12 层物理栈后只剩 `+0.1969`。

## 4. 训练目标

### 4.1 主损失

```
loss = loss_amp + loss_ph
     + GEN_W·loss_gen + SPEC_W·loss_spec + HF_GUARD_W·loss_hf + LO_FLOOR_W·loss_lo
     + BAND_ABS_W·loss_ba + BAND_CAP_W·loss_bc + H_SPEC_W·loss_hs
     + PHASE_BAND_W·loss_pb + PHASE_FLOOR_W·loss_pf
     + DISC_W·loss_disc + MARGIN_W·loss_margin + WCS_W·loss_wcs
     + PRES_W·loss_pres + COLOR_W·loss_color
     + COL_BAND_W·loss_cb + COL_PH_W·loss_cbp + DC_BAND_W·loss_dcb
```

### 4.2 振幅项（log1p 域加权 MSE）

```
la = log1p(a),  lt = log1p(a_tar)
w  = (a_tar / max(a_tar))^AMP_P
loss_amp = mean( w · (la − lt)² )
```

**为什么用 `log1p`**：振幅跨 5~6 个数量级（`1e-8 ~ 1e3`），线性域 MSE 会被大值主导。`log1p` 压缩动态范围，且在 `a→0` 时梯度有界（`log` 在 0 处发散）。

**为什么按 `a_tar` 功率加权**：不加权时高频（振幅极小）的误差被低频淹没，模型倾向放弃高频。

### 4.3 相位项（功率加权）

```
pe = wrap(θ − θ_tar)
w_ph = clamp(a_tar², min=1e-8)
loss_ph = Σ(w_ph · pe²) / Σ w_ph
```

**按振幅平方加权**：振幅大的通道对视觉影响大，其相位必须准；振幅接近 0 的通道相位无意义（噪声）。

配套可观测指标：

```
wcos = Σ(w_ph·cos(pe)) / Σ w_ph        （功率加权相位一致性，∈[−1,1]）
```

`wcos = 1` 表示逐通道相位完全对齐。

### 4.4 谱形状与频段能量项

| 项 | 作用 |
|---|---|
| `loss_spec` | 频谱形状匹配（逐通道 log 幅度差） |
| `loss_hf` | **高频守卫**，单侧：仅在生成高频超 target 一定 slack 时惩罚。防止高频爆（曾出现 100 倍）|
| `loss_lo` | **低频地板**，单侧：防止低频塌陷（DC 承载 97.2% 能量） |
| `loss_ba` | 频段能量占比绝对偏差 |
| `loss_bc` | 频段能量上限约束 |
| `loss_hs` | 时间频率维度（h）的谱监督——该维度长期零监督 |
| `loss_pb / loss_pf` | 分频段相位质量 / 地板 |
| `loss_dcb` | DC 单侧约束：仅在生成 DC 超 target 时罚，避免整体压暗 |

**单侧约束的必要性**：双侧约束（`|生成−目标|`）会导致两个方向的错误互相抵消——把暗画面整体提亮也能降低 loss。必须用 `relu` 单侧惩罚指定方向。

### 4.5 条件判别项

```
loss_disc = relu( cos(dth_self, dth_other) − DISC_TGT_COS )
```
强制**不同条件产生的初始态调制向量互相远离**（余弦低于阈值）。实测 `DISC_TGT_COS=0.40` 时，`cond_init` 输出余弦从 0.814 降到 0.386。

### 4.6 其余正则

| 项 | 作用 |
|---|---|
| `loss_margin` | 绝对相位一致性下限（`wcos_self` 必须超过阈值） |
| `loss_wcs` | `wcos` 直接下限约束 |
| `loss_pres` | 相位残差范数约束（防相位漂移过大） |
| `loss_color` | 颜色（空间域饱和度） |
| `loss_cb / loss_cbp` | **颜色频段**幅度 / 相位，作用于 `w=16` 的 5 个通道 |
| `loss_gen` | 初始态/旁路的直接监督（梯度穿 12 层太长，必须短路） |

**`loss_gen` 的必要性**：条件通路梯度需穿过 12 个物理块，实测 40 步内几乎学不动。因此对 `cond_init` 输出、FFT 旁路输出、条件场预测都加**直接监督**（短路梯度）。

## 5. 显存与计算工程

### 5.1 为什么不能用 fp16 混合精度

| 量 | 性质 | fp16 问题 |
|---|---|---|
| 相位 `θ` | 周期量 `[−π,π]` | 分辨率约 `1e-3 rad`，12 层累积漂移误差指数增长 |
| 振幅 `a` | 跨 5~6 个数量级（`1e-8~1e3`） | 最小正规数 `6e-5`，大量高频系数下溢成 0 → 中高频信息被删 |
| 距离 `‖z‖²` | 求和可达 `~10⁵` | 超 fp16 上限 65504 直接溢出 |

**结论：本架构不能降精度，省显存只能靠重算与状态压缩。**

### 5.2 梯度检查点

对 12 个 `PhysicsBlock` 的循环启用：

```python
checkpoint(blk, a, theta, omega, t_coord, s_coord, use_reentrant=False, **kwargs)
```

前向不保存中间激活，反向重算。**数学完全不变**，仅以约 30% 时间换约 50% 激活显存。`use_reentrant=False` 允许非张量输出（`sync_diag` 是 dict）。

### 5.3 8bit 优化器状态

`bitsandbytes.optim.AdamW8bit`，把 Adam 的 `exp_avg` / `exp_avg_sq` 从 fp32 压到 8bit，优化器状态显存减半。

**依据**：本架构的更新量是动力学系数的增量，二阶矩用 8bit 存储精度足够（与 Transformer 的激活统计不同）。

### 5.4 实测显存占用

`rank=64`（109.12M 参数）+ 梯度检查点 + 8bit 优化器，训练 1 步（含优化器 step）：

```
峰值 allocated = 3695 MiB
reserved       = 3952 MiB / 4096 MiB（余量 144 MiB）
```

**参数量不是显存大头**：23M 参数占 92MB，109M 占 436MB；显存主要被**激活**吃掉（约 3.4GB）。

### 5.5 其它显存约束

| 技术 | 原因 |
|---|---|
| `ACC_K` 梯度累积 | batch 恒为 1，用累积模拟更大 batch |
| `project_w2()` | 每步后把 FFN 输出层权重投影回 `‖w2‖ ≤ W2_NORM_MAX`，防数值爆炸（直接缩放权重，非梯度 hook，保证口径不变） |
| 分块 logsumexp | 见 §2.4 |
| `KAPPA_MAX` 有效值 clamp | 必须对 `tf["kappa"]·kappa` 的**乘积**做 clamp；若只 clamp 单侧（sigmoid 后 ≤2），永远不触发，深块乘积可达 31 → 相位被暴力同步拉平 |

## 6. 推理流程

```
条件向量 cv [1,6147]
   ↓ CondInitPC
初始态 (a_0, θ_0) [1,N,D]
   ↓ 12 × PhysicsBlock（t_coord/s_coord 固定，无梯度）
终态 (a, θ)
   ↓ z = a·e^{iθ} → 实虚分离 [N,2D]
   ↓ decode（×NORM → irfft2 → 逆 reshape → clamp）
30 帧 × 128×128×3
```

**关键性质**：一次前向输出全部 30 帧。时间轴被编码进频率维度（`T_s=6` 个时间频段），因此不存在自回归的逐步生成，也不存在 Diffusion 的多步去噪。

**耗时**：纯前向 + 解码约 **2~4 秒**（RTX 3050 4GB）。

**物理重建模式**：若向 `target_field` 传入目标场，`fft_bypass` 会把它转成逐位置调制叠加到初始态，此时模型执行的是"给定目标场的物理重建"而非无条件生成。实测重建 `PSNR 19.84 dB`、`wcos 0.9991`。
