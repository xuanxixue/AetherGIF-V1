## 二、★ 双生态边界（最关键，务必读）

项目里有**两套完全独立的物理核**，权重不兼容、**禁止交叉覆盖**：

| | 根 `src/`（方案 D） | `v4200/src/`（多模态 CLIP 产品版） |
|---|---|---|
| 参数量 | 1,134,966（默认）/ 2,020,869（d_model=125） | **23,044,534** |
| `a_gamma_lvl` | 0.5（`requires_grad=False` 固定） | 可学习单 γ=0.3 |
| `a_mu` | `log1p(0.05)` = 0.0488 | `log(0.2)` |
| 递推域 | log1p 域统一 | log 域 |
| 条件初始化 | `CondInitModulator` | **`CondInitPC`**（`COND_INIT_PC=1 COND_PC_RANK=8`） |
| 条件通路 | 4 个 `nn.Linear` 头 | `cond_field` chan_amp 调制 + `cond_init_pc` |
| 权重兼容 | 根 `outputs_real/*.pt` | v4200 `outputs_real/*/cond3_ckpt.pt` 等 30+ 个 |

**加载 v4200 ckpt 的必备环境变量**：
```
COND_INIT_PC=1
COND_PC_RANK=8
```
漏掉这两个 → `load_state_dict` shape mismatch（`cond_init.to_amp.1.weight` 768000×8 vs 6144×16）。

## 四、关键超参（铁律，勿改）

```
D=125, GRID=32, PATCH=4, WIN=5, IMG=128, TS=6, NORM=10.0
```

- `rfft2` 真实网格 = 5 × 25 = **125**。通道 c ↔ (h=c//25, **w=c%25**)，分频段必须按 w 切。
- `spec[:, :d_model]` 的**非对称硬截断**是网格感真凶（2026-10-12 定位）。全保留 125 系数时 PSNR 147.20 dB、网格比 = 素材原值。
- 振幅走 log1p 域、相位走 `a_tar²` 功率加权。诊断谱包络必须与 loss 聚合顺序一致（`mean_N(log)` 而非 `log(mean_N(a))`）。
- OU 平衡点必须 **per-channel**（FFT 每通道振幅均值跨 727 倍）。
- `ω` 必须确定性（每次前向重采样 = 换动力系统）。
- 振幅演化必须 **log 域乘性**：`a_new = a·exp(clamp(ffn_out,−6,3))`。

## 九、运行时审查与加固（2026-10-23 深夜，第二轮）

新增 `tools/runtime_probe.py`：真实调用双生态全链路（不是静态检查）。
**必须分进程** —— 根 `src/` 与 `v4200/src/` 顶层包名相同（model/physics/codec/data/train），
同进程第二次 `import model` 会命中 `sys.modules` 缓存拿到另一生态的模块。

### 修掉的 3 个 bug（均为"不报错但白跑/损坏"型）

| # | 位置 | 问题 | 修法 |
|---|---|---|---|
| 1 | `v4200/scripts/train_guided.py` | 漏设 `COND_INIT_PC` 会静默退化成旧 Modulator（10.27M vs 23.04M），`RESUME` 再把 `cond_init.*` 当 shape 不匹配跳过 → **条件通路随机初始化，几小时白跑** | 补 `setdefault("COND_INIT_PC","1")` + `COND_PC_RANK="8"`（可显式覆盖）。**`overfit_cond3.py` 不加**，它服务 fix_r 旧架构 |
| 2 | `train_guided.py` / `overfit_cond3.py` | 裸 `torch.save` 直接写目标文件：Windows 文件被占用抛 PermissionError（color4 实际崩在这，20 分钟白跑）；中途失败留**半截 ckpt 覆盖好权重** | 加 `_safe_torch_save()`：写 `.tmp<pid>` → `os.replace` 原子替换，6 次递增重试，失败保留 tmp 可人工恢复 |
| 3 | 同上两脚本 | `RESUME` 路径不存在时静默 `print("忽略")` 然后继续 → 明确指定续训却变成随机初始化 | 默认 `RESUME_STRICT=1`，找不到即 `SystemExit(2)`；跳过**关键条件层**（exclude `.0.weight` 低秩层）即 `SystemExit(3)` |

### 双生态架构口径（不可混）

`cond_init.to_amp.1.weight` 的形状就是身份证：
- `(768000, 8)` = **CondInitPC**（color1 起的 v4200 产品版，23,044,534 参数）
- `(30720, 16)` = **旧 CondInitModulator**（fix_r 系列，10,273,206 参数）

续训前必须确认 ckpt 与 `COND_INIT_PC` / `COND_PC_RANK` 口径一致，否则会触发上面 bug 1。
