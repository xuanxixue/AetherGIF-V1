## 7. 质量验收基准（交接文档）

图像空间，PATCH=4：

```
原始素材        边界4.99 内部4.94 网格比1.010 std42.8 Sobel4.20
codec天花板     边界6.81 内部5.59 网格比1.218 std35.9 Sobel4.89
（v3700 卡在这附近，v4200 不应更好，但不能明显更差）
```

验收线：生成质量不低于 v3700_D125_修复烧焦。

验收判据（auto_accept.py）：
1. 对比度 std ≥ codec 天花板 85%
2. PSNR ≥ v2500 − 0.5
3. 频段能量占比偏差 ≤ 1.5pp
4. 过曝 < 1.5% 且无崩塌帧（相对 target）
