## 4. 关键口径常量汇总（来自代码）

### 4.1 编解码口径（train_multimodal.py 第142行）

```python
D, GRID, PATCH, WIN, IMG, TS = 125, 32, 4, 5, 128, 6
H_FFT, W_FFT = WIN, (PATCH * PATCH * 3) // 2 + 1
```

- `D=125`：振子通道数（rfft2 真实网格 5×25=125）
- `GRID=32`：空间网格 32×32
- `PATCH=4`：4×4像素块
- `WIN=5`：5帧时间窗口
- `IMG=128`：128×128分辨率
- `TS=6`：6个时间步（3秒@10fps）
- `H_FFT=5`, `W_FFT=25`
