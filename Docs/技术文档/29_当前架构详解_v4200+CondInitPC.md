# 29 · AetherGIF-V1 当前架构详解（v4200 + CondInitPC，2026-10-22）

> 本文是**当前模型**的完整架构解析：每个区域代表什么、数据怎么流、维度怎么变、
> 每一处设计对应历史上哪个死穴/发现。配合《28》的迭代记录阅读。

## 1. 一句话总览

**GIF → 3D FFT 复值场 → 物理振子演化（12 层纯物理核，零 Transformer）→ 逆 FFT → GIF**。
条件（文本/首帧/GIF 三模态向量）不经过任何注意力机制，而是调制**振子的初始状态**，
让动力学自己把条件「演化」成画面。这是与 Transformer/Diffusion 路线的本质区别。

## 3. 一张表看完「每个区域为什么长这样」

| 区域 | 回答的问题 | 历史依据（死穴/发现） |
|---|---|---|
| A 区三路同空间 | 为什么不用投影矩阵？ | 三路都出自 Qwen3-VL 同一 2048 维 L2 归一空间（10-16 用户定调） |
| B 区 FFT 只编码 | 为什么不做有损压缩瓶颈？ | 第三十五个发现：FFT 系数重尾，任何瓶颈都掉 dB |
| C 区 softmax 融合 | 为什么权重和恒为 1？ | 防三路整体同步放大；单路仍可学到趋近 0 |
| D 区 ω 确定性 | 为什么 ω 不能随机？ | 每次前向重采样 ω = 每次换动力系统，无法学习 |
| E 区 θ̂ 逐通道 | 为什么不用 G=5？ | 第三十六个发现：G=5 是容量天花板（teacher 口径也只有 13.76 dB） |
| E 区 arctan×2 | 为什么不用 tanh？ | tanh 饱和 + 只覆盖半圆；arctan×2 覆盖 (−π,π] 全圆 |
| E 区低秩 R=8 | 为什么不全连接？ | 4GB 约束：hidden→N·D 单层 1.46GB 直接 OOM；低秩两头共 13.8M 参数 |
| F 区 dropout | 训练/推理为什么不能总一致？ | keep 步把答案喂进 fft_bypass → 条件通路从不是必需（guid1 实证钉死 0 地板） |
| G 区 κ 上限 | 为什么 clamp？ | 第三十死穴：κ 随块号涨到 15.8，cos(θ) 从 +1.0 掉到 +0.36 |
| G 区模块门 | 为什么不全连接？ | 全连接 → 全局同步坍缩 → 梯度归零（Un-0 稀疏耦合范式） |
| G 区 log 域振幅 | 为什么不用 LayerNorm/softplus？ | 第一死穴：加性+归一化抹平重尾；乘性 exp 才能保动态范围 |
| I 区 a² 相位加权 | 为什么不用均匀加权？ | 第三死穴：69.4% 系数幅度 <0.01，其 θ_tar 是纯数值噪声 |

## 4. 维度流水的全程账本（B=1）

```
cond_vec      [1, 6147]                     ← A 区
h             [1, 512]                      ← E 区 proj
θ̂ / â        [1, 6144, 125]                ← E 区（逐通道）
a0 / θ0       [1, 6144, 125]                ← D 区随机 → E 区调制后 = â / θ̂
omega         [1, 6144, 125] = base + bias  ← ω 确定性
target_field  [1, 6144, 250] = [a|θ] 拼接   ← B 区（仅训练）
  └─ 125 = WIN(5 时间窗) × W_FFT(25 频率列)
      通道 c ↔ (h=c//25, w=c%25)；分频段必须按 w 切（第二十三死穴）
      content 层 = w=0 列（c=0/25/50/75/100），承载 97.2% 能量
block×12      (a,θ) [1, 6144, 125] 循环演化  ← G 区
最终 (a,θ)    [1, 6144, 125] → 逆 FFT        ← H 区
GIF           30 帧（TS=6 × WIN=5）× 128×128×3
```

## 5. 与 Transformer/Diffusion 路线的本质差异（融资讲解口径）

| 维度 | Transformer/Diffusion | AetherGIF（本架构） |
|---|---|---|
| 生成机制 | 注意力/去噪迭代 | **物理动力学演化**（Kuramoto + OU + 驻波） |
| 条件注入 | cross-attention | **调制振子初始态 + 漂移锚** |
| 参数规模 | 数亿~数十亿 | 23M（同样的任务） |
| 显存 | 10GB+ | **3.93GB 可训练，推理更省** |
| 架构里有没有 Transformer | 有 | **零**（唯一 nn.Linear 服务 Qwen 冻结编码器，不在主干） |
