## 2. v3800 · 方案 B：频率依赖衰减率

### 2.1 目的

给 Kuramoto 的空间耦合加上**频率选择性**，让高频传得更短 → 从耦合层面治烧焦感。

### 2.2 现状诊断（方案说明引用 v3700 代码原文）

`src/physics/kuramoto_sync.py` 的 `ToeplitzKernel.apply_coupling`：

```python
spatial_W = torch.exp(-self.lambda_s * s_scale * (diff ** 2).sum(-1))   # [1024,1024]
```

`lambda_s` 是**标量**，所有频率用同一个衰减率。

### 2.3 方案

```
λ_s(f) = λ_base · (1 + β · log(f_norm + 1))      β 可学
```

物理含义：**色散介质**——高频成分在空间上衰减更快。

### 2.4 改动点与风险

| 项 | 值 |
|---|---|
| 文件 | `src/physics/kuramoto_sync.py`（**单文件**） |
| 位置 | `apply_coupling` 里构造 `spatial_W` 那一行 |
| 参数量 | **+1**（β） |
| 保证 | β 初值 0（等价于当前行为），训练中学出来 |
| 风险 | **极低**（不动任何其他结构，β=0 时与 v3700 完全等价，可做严格对照） |

### 2.5 为什么排第一位（方案说明原文）

> **参数量最小（1 个）、改动面最小（单文件）、物理直觉最强**，而且直击「高频能量堆积」的病根——高频传不远，自然不会在远处堆积。

### 2.6 验证判据（设计但从未执行）

1. β 是否从 0 变成非 0（学出来了）。
2. 高频增益 / Nyquist 环读数是否比 v3700 更低。
3. 空间域 Sobel、frame-diff 是否改善且 std 不崩。

## 3. v3900 · 方案 A：可学耦合修正

### 3.1 核心洞察

当前空间耦合**本来就是 [1024,1024] 的稠密矩阵**，只是用解析式 Toeplitz 构造。所以「结构性选择」与「学出来的选择」**不是二选一**，可以在同一个矩阵上叠加。

### 3.2 方案

```
W_ij = exp(-λ_t·|Δt| - λ_s·|Δs|²) · α_ij
       └────── 结构性骨架（不可学）──────┘   └─ 内容选择（可学）─┘
```

α 从已有的 4 个文本注入头派生（复用 `omega_bias_head` 那套模式）。

### 3.3 改动点与风险

| 项 | 值 |
|---|---|
| 文件 | `src/physics/kuramoto_sync.py` + `src/model/aether_gif_model.py` |
| 参数量 | **~125**（按频段学缩放系数） |
| 硬约束 | ⚠️ **不要学完整 [1024,1024]**——那是 100 万参数 × 12 层 = 1200 万，违背「架构中不得出现可学习大矩阵」的硬约束 |
| 风险 | **中**（α 若随输入变化，每步前向要多算一次；12 层叠加可能放大振荡） |

### 3.4 验证判据（设计但从未执行）

1. α 是否真的随文本/输入变化（不能是常量）。
2. 对照实验：固定 α 为 1（即退化成 v3700）作为严格 baseline。
3. 跨文本生成的可区分度（直接关联研究报告里「能力 B 最小闭环」）。

### 3.5 排序逻辑（方案说明原文）

> 如果方案 B（频率依赖衰减）有效，说明**耦合层面确实需要频率选择性**，那这个方案就是在那个方向上再加「内容自适应」。如果方案 B 无效，再考虑这个——因为它改动更大。

## 4. v4000 · 方案 C：热力学正则

### 4.1 关键前提：Thermodynamics 当前是 0 梯度接入的

方案说明原文引用代码：

```python
class Thermodynamics(nn.Module):
    """热力学判据层：U / S / F，只做诊断，不参与梯度。"""
```

全项目搜索只有 import / `self.thermo = Thermodynamics()`（实例化未用）/ 文档字符串三处，**loss 里没有任何一项引用 U、S、F**。

由此推出两个纠正：
- 网上/第三方建议里「新热分布会与现有 −T·S 冲突」的前提**不成立**（−T·S 从未生效）；
- 「热力学层已经在管这件事只是方向不对」**同样是错的**（它根本没在管）；
- **本方案等于新增一条梯度通路，风险最高，必须放最后做**。

### 4.2 附带发现的 bug（顺手记录）

`thermodynamics.py` 的 `amplitude_entropy_channel`：

```python
p = F.softmax(a, dim=1)          # 注释说"每个通道一个分布"
S = -(p * torch.log(p+1e-12)).sum(dim=1)
return S / torch.log(torch.tensor(float(a.shape[1])))   # 归一化也按 N
```

注释说「通道维」，实现是沿 **N 维** softmax，归一化也按 N 算——**实现与文档不一致**。因为未参与训练所以暂不影响，但启用前必须先修。

> 注：此 bug 在主代码 `src/physics/thermodynamics.py` 中**至今存在**（见文档 05 的「文件头与代码的不一致」章节）。

### 4.3 方案

定义频率能量作为**单边正则项**加进 loss，用温度调度控制权重：

```
E_freq = Σ_c w_c · a_c²,     w_c 随频率递增
λ(T) = λ_max · (T / T_max)    早期高温允许探索，后期低温压制高频
```

### 4.4 改动点与风险

| 项 | 值 |
|---|---|
| 文件 | `src/physics/thermodynamics.py`（修 bug + 加能量项）、`scripts/overfit.py`（加 loss） |
| 参数量 | **~2** |
| 前置 | 先修 `amplitude_entropy_channel` 的维度问题 |
| 风险 | **中高**（会同时影响 U（相位锁）和 S（振幅均匀）两个**已经工作的方向**，而当前高通过冲是纯粹的单边问题，S 的「驱向均匀」不一定对症） |

### 4.5 排序逻辑（方案说明原文）

> **这是最重的一个方案，只有在 A 和 B 都证明「耦合层面解决不了」时才值得做。** 优先做最小验证（单边 E_freq 正则），不要一上来上完整的 F=U−TS 框架。

## 5. v4100 · 三场分层注意力（唯一写了代码的新方案）

### 5.1 新增文件：`src/physics/field_attention.py`（89 行）

这是 v4100 相对 v3600/v3700 的唯一新增模块。以下按代码逐行分析。

#### 5.1.1 文件头声明的问题

```
模型没有"内容性选择"：Kuramoto 耦合只看空间距离（Toeplitz 衰减）和全局相位
（平均场），不看两个频点承载的内容是否相关，导致噪声和细节被无差别耦合/学习。
```

#### 5.1.2 三场分层的定义（用户定义，docstring 明确「与华为 WEWA 命名无关，概念独立成立」）

| 场 | 含义 | 处理方式 |
|---|---|---|
| 核心场 core | 该学的（结构、必须保真的内容） | couple_g 全参与 + learn_g=1 |
| 边缘场 edge | 需泛化的（可软化拟合、但要在空间上连贯） | learn_g = sigmoid(edge_soften) |
| 外层场 outer | 绝不能学的（纯噪声，学了=过拟合=烧焦感） | couple_g=0（隔离）+ learn_g=0 |

#### 5.1.3 关键设计约束（docstring 明确标注「本条是用户本人纠正，务必守住」）

**场归属与频率位置无关。** 低频完全可能是大面积闪烁噪声（应进外层场），高频完全可能是锐利边缘细节（应进核心场）。因此：

- ✗ 禁止用「低频→核心 / 中频→边缘 / 高频→外层」的单调 sigmoid 切点（w1 < w2 沿频率轴切分 = 拍脑袋锁死，正是项目犯过的错）
- ✓ 每个频点 c 持有自己独立的三个 logits，softmax 归一为 (g_core, g_edge, g_outer)——频点之间无共享、无平滑、无频率序诱导，归属完全由数据自己分化

#### 5.1.4 公式

```
g_core(c), g_edge(c), g_outer(c) = softmax(logits_c)        （和 = 1，互斥分配）

生效点 1（耦合隔离）：couple_g(c) = g_core(c) + g_edge(c)  = 1 − g_outer(c)
  乘进 Kuramoto 耦合矩阵的「源端」，外层场通道不再向其它振子传播噪声相位。

生效点 2（学习强度）：learn_g(c) = g_core(c) + edge_w · g_edge(c)
  edge_w = sigmoid(edge_soften) ∈ (0,1)，边缘场在 loss 上被软化（只泛化不硬拟合）。
  learn_g 乘进振幅 loss，外层场通道的振幅惩罚归零 = 停止学习噪声系数。
```

#### 5.1.5 参数量

| 参数 | 形状 | 数量 |
|---|---|---|
| field_logits | D×3（D=125） | 375 |
| edge_soften | 标量 | 1 |
| **合计** | | **376** |

相对基线 2,022,232 仅 +0.019%。docstring 的说明：「不加任何可学习的内容相似度打分器，只加一段『该学谁』的归属表」。

#### 5.1.6 初始化

```python
logits = torch.zeros(d_model, 3)
logits[:, 0] = core_init        # core_init = 5.0
self.field_logits = nn.Parameter(logits)
self.edge_soften = nn.Parameter(torch.tensor(0.0))
```

`softmax([5,0,0]) ≈ [0.928, 0.036, 0.036]` → couple_g≈0.964, learn_g≈0.946。即初始所有频点几乎都是核心场，**行为与基线近乎一致（从基线起步）**，随后由数据把噪声频点逐批「推出」到 edge/outer。

docstring 明确区别：「切点是**人规定**的频率单调函数，这里是**逐频点自由参数**，两者的梯度自由度完全不同」。

#### 5.1.7 forward 返回值

```python
def forward(self):
    g = self.field_probs()                       # [D, 3]
    g_core, g_edge, g_outer = g[:, 0], g[:, 1], g[:, 2]
    edge_w = torch.sigmoid(self.edge_soften)
    couple_g = g_core + g_edge                    # = 1 − g_outer
    learn_g = g_core + edge_w * g_edge
    return couple_g, learn_g
```

### 5.2 集成方式（v4100 vs v3600 的 diff 实证）

**`src/physics/block.py`**（3 处改动）：

