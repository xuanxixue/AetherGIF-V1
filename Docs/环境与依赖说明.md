## 二、三个必挂路径

```python

sys.path.insert(0, r'D:/AetherGIF-V1')            # ① torch_accel_shim 在根目录
```

### ① `torch_accel_shim` —— 必须在 import transformers **之前**调用

transformers 5.x 硬依赖 `torch.accelerator`，而 torch 2.5.1 没有这个模块，直接 import 会报
`Could not import module 'AutoModelForCausalLM'`。

```python
from torch_accel_shim import install_full
install_full()
```

### ② `deps312/` —— 为什么不能直接用 site-packages

`C:\Python312\Lib\site-packages\transformers` 是**残缺的**（4.38.2 与 4.44.2 互相覆盖，只剩 4 个文件，
缺 `utils/versions.py`），报 `ModuleNotFoundError: No module named 'transformers.utils.versions'`。
完整版 5.19.0 在 `D:\AetherGIF-V1\deps312`，挂到 path 前面即可。

### ③ `int8_deps/` —— `qwen_vl_utils` 在这里

不在 site-packages，漏挂会报 `ModuleNotFoundError: No module named 'qwen_vl_utils'`。

### 数据根上溯机制
v4200 的脚本用 `_resolve_gif_root()` 从脚本目录向上退 3~6 级动态找 `data/gif_raw`。
历史上曾写成退 3 级 → 指向不存在的 `docx/data/gif_raw` → 14145 张全部被静默跳过、
脚本照样退出码 0 并打印「成功 0/14145」。**静默失败比报错更难查**——现在该脚本启动即断言数据根存在。

## 七、检查清单（跑训练前）

1. `py_compile` 目标脚本（曾遇训练结束后有人改脚本留未定义变量的半成品）
2. `ls` 确认 `overfit_ckpt_best.pt` 存在（旧脚本可能没有最佳留档逻辑）
3. 试跑带 `OVERFIT_TAG=<tag>`，产物落 `outputs_real/<tag>/`（避免覆盖已训好的 ckpt）
4. 改 loss 先跑 150 步比同步数指标，方向错立刻终止
5. GPU 只有 4GB，保持 `batch=1`
6. 任何物理核改动先跑 50 步逐 step 体检（a_range / wmax / NaN）
